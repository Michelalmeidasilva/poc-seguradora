# Chatbot: Plano de Implementação (Plano 3 de 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `apps/chatbot`: a API interna que recebe cada evento do usuário do gateway (`POST /v1/chat/events`), conduz o diálogo (menu, cotação por Flow, consulta de apólices e segunda via, abertura e consulta de sinistro), consulta os serviços internos com resiliência e responde em NDJSON, de forma idempotente por `event.id`.

**Architecture:** Hexagonal (`domain` / `application` / `infra` / `main.ts`) em Fastify 5. O **domínio é puro**: uma máquina de estados (`next(state, input)`) devolve ou respostas prontas (`ReplyBody`) ou uma *chamada de serviço com continuação* (`ServiceCall.then`), sem I/O; o catálogo de mensagens (inclusive o JSON do Flow de cotação) e o `TurnLog` (replay idempotente) também são puros. A camada de aplicação (`HandleTurn`) executa o laço: classifica o texto pelo LLM (porta `LlmProvider`, com mock determinístico), roda `next`, executa as chamadas pela porta `ServicesPort` e publica os eventos no `TurnRecord`, que qualquer chamada com o mesmo `event.id` lê (replay ou acompanhamento ao vivo). A infraestrutura traz o mock do LLM com guardas, os clientes HTTP dos três serviços (camada anticorrupção + `createPolicy` por serviço) e a rota Fastify que envia os **cabeçalhos primeiro** e depois as linhas NDJSON.

**Tech Stack:** Node 22, TypeScript estrito, Fastify 5, pino, Zod 3, Vitest, `tsup`, `dependency-cruiser` (já configurado no repositório).

**Specs:**
- `docs/superpowers/specs/2026-10-10-gateway-chatbot-contract.md` (**contrato obrigatório** deste serviço com o gateway)
- `docs/superpowers/specs/2026-10-10-internal-services-contracts.md` (APIs de cotação, apólice e sinistro que o chatbot consome)
- `docs/superpowers/specs/2026-10-10-whatsapp-chatbot-poc-design.md` (seções 5, 7, 9, 10, 14)

Código existente que este plano consome (já na `master`): `@seguradora/protocol` (`ChatbotRequestSchema`, `UnsequencedServerEvent`, `parseChatbotLine`, `serializeChatbotLine`, `Result`/`ok`/`err`, `LIMITS`) e `@seguradora/resilience` (`createPolicy`, `CircuitBreaker`, `Bulkhead`, `TimeoutError`, `withTimeout`).

**Execução:** em uma branch nova `feat/chatbot`, de preferência em um `git worktree` próprio, partindo da `master`.

## Dependência dos serviços internos

Os serviços `svc-cotacao`, `svc-apolice` e `svc-sinistro` são feitos por outro agente e **podem ainda não existir**. Por isso este plano não depende deles: todos os testes usam um **servidor fake** (`test/fake-services.ts`) que implementa o contrato do documento de serviços, incluindo os fixtures obrigatórios (CPF `12345678901` com `AP-1001` ATIVA, `AP-1002` VENCIDA e `AP-1003` CANCELADA; sinistro `SN-2001`; novos protocolos a partir de `SN-2002`; cotação `CT-3001`). Quando os serviços reais existirem, rode o chatbot contra eles manualmente (nota nas pendências do `CHECKLIST.md`).

## Global Constraints

- Um único repositório git na raiz. Nunca `git init` dentro de `apps/*` ou `packages/*`.
- TypeScript `strict`; Node ≥ 22.12; pnpm monorepo; validação nas bordas com Zod 3; erros esperados como `Result`.
- Arquitetura hexagonal: dependências só em `infra → application → domain`; o domínio não importa Fastify, pino nem jose (`dependency-cruiser` verifica no CI); injeção manual no composition root (`compose.ts` e `main.ts`).
- Contrato com o gateway (documento acima): `POST /v1/chat/events` → `200` `application/x-ndjson`, uma linha por `UnsequencedServerEvent` (sem `seq`), cada linha terminada em `\n`, **cabeçalhos enviados imediatamente** (antes de chamar qualquer serviço), o chatbot **não** emite `status.delivered`, `sessionId`/`correlationId` iguais aos da requisição em todos os eventos, linha ≤ 262144 caracteres.
- Idempotência: o mesmo `event.id` nunca executa duas vezes; uma chamada repetida devolve as **mesmas linhas, com os mesmos `id` de evento**, ou acompanha a execução em andamento.
- O chatbot repassa o `correlationId` do corpo como `x-correlation-id` a todo serviço interno e usa o `event.id` como `Idempotency-Key` nos `POST`.
- Falhas de serviço viram mensagem amigável ao usuário (nunca 5xx para o gateway por causa de um serviço); exceções inesperadas viram evento `error` `internal_error`.
- Logs estruturados (pino) sem dados pessoais: nunca logar texto do usuário, CPF, nome nem corpos de resposta dos serviços; mensagens de erro de parsing sem conteúdo (apenas caminho e código).
- Dados de usuário nunca entram em URL sem validação: números de apólice `^AP-\d{3,6}$`, protocolos `^SN-\d{3,6}$`, CPF 11 dígitos; sempre `encodeURIComponent`.
- Commits convencionais; atualizar `CHECKLIST.md` no mesmo commit que conclui o item; reivindicar a frente no `WORKBOARD.md` antes de codar (skill `workboard-protocol`); `prettier --write` pela raiz antes de comitar.
- Identificadores e comentários de código em inglês; textos para o usuário e documentação em português.

## Review Focus

Entradas que o spec não detalha e que mais provavelmente quebram:

1. **Mesmo `event.id` repetido enquanto o primeiro turno ainda roda** deve acompanhar o turno em andamento e devolver exatamente as mesmas linhas (mesmos `id`), chamando cada serviço uma única vez. Testes nas Tarefas 4, 5 e 9.
2. **Cabeçalhos primeiro:** com um serviço lento, os cabeçalhos `200` precisam chegar antes do primeiro byte do corpo e bem antes do timeout de conexão do gateway (5 s). Testes nas Tarefas 8 e 9.
3. **Serviço indisponível no meio de uma jornada** deve gerar mensagem amigável e **manter** o estado do diálogo (o usuário reenvia o último passo), nunca deixar o diálogo corrompido. Testes nas Tarefas 3, 5 e 9.
4. **Texto livre que parece intenção** (descrição de sinistro: "bati o carro, colisão no estacionamento") não pode reiniciar o fluxo quando o estado espera texto livre; só `cancelar` interrompe. Teste na Tarefa 3.
5. **Entradas hostis em URLs e corpos:** `policy:AP-1/../../x`, `%2F`, CPF com letras, descrição enorme, `flow_submit` com chaves estranhas (`__proto__`) ou valores gigantes devem ser rejeitados ou ignorados antes de montar URL ou corpo para um serviço. Testes nas Tarefas 2, 3 e 7.

```ts
import { err, ok, type Result } from '@seguradora/protocol';
import { z } from 'zod';

/** An empty env string (`KEY=`) behaves like a missing key. */
const blankAsMissing = (v: unknown) => (v === '' ? undefined : v);
const optional = <T extends z.ZodTypeAny>(schema: T) => z.preprocess(blankAsMissing, schema);

const int = (fallback: number, min = 0) =>
  optional(z.coerce.number().int().min(min).default(fallback));

export const ConfigSchema = z
  .object({
    PORT: optional(z.coerce.number().int().min(1).max(65535).default(8080)),
    HOST: optional(z.string().min(1).default('0.0.0.0')),
    LOG_LEVEL: optional(
      z.enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent']).default('info'),
    ),
    COTACAO_URL: z.string().url(),
    APOLICE_URL: z.string().url(),
    SINISTRO_URL: z.string().url(),
    SERVICE_TIMEOUT_MS: int(4000, 1),
    SERVICE_RETRIES: int(2, 0),
    SERVICE_RETRY_BASE_MS: int(100, 0),
    SERVICE_RETRY_MAX_MS: int(1000, 0),
    BREAKER_FAILURE_THRESHOLD: int(5, 1),
    BREAKER_RESET_MS: int(10000, 0),
    BULKHEAD_MAX_CONCURRENT: int(10, 1),
    BULKHEAD_MAX_QUEUE: int(20, 0),
    LLM_TIMEOUT_MS: int(1500, 1),
    LLM_MAX_INPUT_CHARS: int(1000, 1),
    TURN_LOG_CAPACITY: int(500, 1),
    SESSION_CAPACITY: int(2000, 1),
    SESSION_TTL_SECONDS: int(3600, 60),
  })
  .superRefine((c, ctx) => {
    if (c.SERVICE_RETRY_MAX_MS < c.SERVICE_RETRY_BASE_MS) {
      ctx.addIssue({
        code: 'custom',
        path: ['SERVICE_RETRY_MAX_MS'],
        message: 'SERVICE_RETRY_MAX_MS must be >= SERVICE_RETRY_BASE_MS',
      });
    }
  });

export type Config = z.infer<typeof ConfigSchema>;

export function loadConfig(env: Record<string, string | undefined>): Result<Config, string[]> {
  const r = ConfigSchema.safeParse(env);
  if (r.success) return ok(r.data);
  return err(r.error.issues.map((i) => `${i.path.join('.') || 'config'}: ${i.message}`));
}
```

```ts
/**
 * Returns the 11 digits of a CPF typed with or without punctuation, or undefined.
 * Only the format is checked: the fixtures of the internal services use fictitious CPFs
 * without valid check digits.
 */
export function normalizeCpf(text: string): string | undefined {
  const trimmed = text.trim();
  if (!/^[\d.\-]+$/.test(trimmed)) return undefined;
  const digits = trimmed.replace(/[.\-]/g, '');
  return /^\d{11}$/.test(digits) ? digits : undefined;
}

  const trimmed = s.trim();
  return PROTOCOL_RE.test(trimmed) ? trimmed.toUpperCase() : undefined;
}
```

```ts
import { err, ok, type Result } from '@seguradora/protocol';
import { z } from 'zod';
import type { QuoteRequest } from './models';

const digits = (s: string) => s.replace(/\D/g, '');
const cpf = z
  .string()
  .transform(digits)
  .refine((d) => d.length === 11, 'invalid');
const cep = z
  .string()
  .transform(digits)
  .refine((d) => d.length === 8, 'invalid');
const reais = z.coerce.number().positive().max(1_000_000_000);

const common = {
  nome: z.string().trim().min(3).max(100),
  cpf,
  nascimento: z.string().regex(/^\d{4}-\d{2}-\d{2}$/),
};

const Submit = z.discriminatedUnion('produto', [
  z.object({
    produto: z.literal('AUTO'),
    ...common,
    marca: z.string().trim().min(1).max(40),
    modelo: z.string().trim().min(1).max(40),
    ano: z.coerce.number().int().min(1980).max(2100),
    cep,
  }),
  z.object({
    produto: z.literal('RESIDENCIAL'),
    ...common,
    cep,
    tipoImovel: z.enum(['CASA', 'APARTAMENTO']),
    valorImovel: reais,
  }),
  z.object({ produto: z.literal('VIDA'), ...common, capital: reais }),
]);

const toCentavos = (r: number): number => Math.round(r * 100);

/**
 * Maps the data of a completed cotacao Flow to a quote request. The error lists only the
 * names of the offending fields, never the values the user typed.
 */
export function parseQuoteSubmit(data: unknown): Result<QuoteRequest, string> {
  const r = Submit.safeParse(data);
  if (!r.success) {
    const fields = [...new Set(r.error.issues.map((i) => i.path.map(String).join('.') || 'form'))];
    return err(`invalid fields: ${fields.join(', ')}`);
  }
  const s = r.data;
  const cliente = { nome: s.nome, cpf: s.cpf, dataNascimento: s.nascimento };
  switch (s.produto) {
    case 'AUTO':
      return ok({
        produto: 'AUTO',
        cliente,
        dados: { veiculo: { marca: s.marca, modelo: s.modelo, ano: s.ano }, cep: s.cep },
        coberturas: [],
      });
    case 'RESIDENCIAL':
      return ok({
        produto: 'RESIDENCIAL',
        cliente,
        dados: { cep: s.cep, tipoImovel: s.tipoImovel, valorImovelCentavos: toCentavos(s.valorImovel) },
        coberturas: [],
      });
    case 'VIDA':
      return ok({
        produto: 'VIDA',
        cliente,
        dados: { capitalSeguradoCentavos: toCentavos(s.capital) },
        coberturas: [],
      });
  }
}
```

```ts
import type { Result } from '@seguradora/protocol';
import type { ServiceCall, Step } from '../domain/dialog';
import type {
  Claim,
  ClaimOpened,
  Policy,
  PolicySummary,
  Quote,
  SecondCopy,
  ServiceFailure,
} from '../domain/models';

export interface Fakes {
  listPolicies?: Result<PolicySummary[], ServiceFailure>;
  getPolicy?: Result<Policy, ServiceFailure>;
  secondCopy?: Result<SecondCopy, ServiceFailure>;
  createQuote?: Result<Quote, ServiceFailure>;
  openClaim?: Result<ClaimOpened, ServiceFailure>;
  getClaim?: Result<Claim, ServiceFailure>;
}

export type ReplyStep = Extract<Step, { kind: 'reply' }>;

/** Runs a dialog step to its final reply, answering each service call with a canned result. */
export function drive(first: Step, fakes: Fakes): { final: ReplyStep; calls: ServiceCall[] } {
  const calls: ServiceCall[] = [];
  let step = first;
  while (step.kind === 'call') {
    const call = step.call;
    calls.push(call);
    const missing = () => new Error(`no fake result for ${call.op}`);
    switch (call.op) {
      case 'listPolicies':
        if (!fakes.listPolicies) throw missing();
        step = call.then(fakes.listPolicies);
        break;
      case 'getPolicy':
        if (!fakes.getPolicy) throw missing();
        step = call.then(fakes.getPolicy);
        break;
      case 'secondCopy':
        if (!fakes.secondCopy) throw missing();
        step = call.then(fakes.secondCopy);
        break;
      case 'createQuote':
        if (!fakes.createQuote) throw missing();
        step = call.then(fakes.createQuote);
        break;
      case 'openClaim':
        if (!fakes.openClaim) throw missing();
        step = call.then(fakes.openClaim);
        break;
      case 'getClaim':
        if (!fakes.getClaim) throw missing();
        step = call.then(fakes.getClaim);
        break;
    }
  }
  return { final: step, calls };
}
```

```ts
import type { Result } from '@seguradora/protocol';
import * as catalog from './catalog';
import {
  CLAIM_TYPES,
  isPolicyNumber,
  normalizeCpf,
  normalizeProtocol,
} from './identifiers';
import type {
  Claim,
  ClaimOpened,
  ClaimRequest,
  ClaimType,
  Policy,
  PolicySummary,
  Quote,
  QuoteRequest,
  SecondCopy,
  ServiceFailure,
} from './models';
import { parseQuoteSubmit } from './quote-submit';
import type { ReplyBody } from './reply';

export type IntentName =
  | 'greeting'
  | 'quote'
  | 'policies'
  | 'claim'
  | 'claim_status'
  | 'location'
  | 'help'
  | 'cancel'
  | 'unknown';

export interface Intent {
  name: IntentName;
  entities: { cpf?: string; apolice?: string; protocolo?: string };
}

export type DialogState =
  | { name: 'idle' }
  | { name: 'quote.awaiting_flow' }
  | { name: 'policies.awaiting_cpf' }
  | { name: 'policies.awaiting_choice'; numeros: string[] }
  | { name: 'claim.awaiting_cpf' }
  | { name: 'claim.awaiting_policy'; numeros: string[] }
  | { name: 'claim.awaiting_type'; apolice: string }
  | { name: 'claim.awaiting_description'; apolice: string; tipo: ClaimType }
  | { name: 'claim_status.awaiting_protocol' };

export const IDLE: DialogState = { name: 'idle' };

export type Input =
  | { kind: 'text'; text: string; intent: Intent }
  | { kind: 'choice'; optionId: string }
  | { kind: 'flow_submit'; flowId: string; data: unknown }
  | { kind: 'voice'; durationMs: number };

type Outcome<T> = Result<T, ServiceFailure>;

/** A call to an internal service, with the continuation that turns its result into the next step. */
export type ServiceCall =
  | { op: 'listPolicies'; cpf: string; then: (r: Outcome<PolicySummary[]>) => Step }
  | { op: 'getPolicy'; numero: string; then: (r: Outcome<Policy>) => Step }
  | { op: 'secondCopy'; numero: string; then: (r: Outcome<SecondCopy>) => Step }
  | { op: 'createQuote'; request: QuoteRequest; then: (r: Outcome<Quote>) => Step }
  | { op: 'openClaim'; request: ClaimRequest; then: (r: Outcome<ClaimOpened>) => Step }
  | { op: 'getClaim'; protocolo: string; then: (r: Outcome<Claim>) => Step };

export type Step =
  | { kind: 'reply'; state: DialogState; replies: ReplyBody[] }
  | { kind: 'call'; call: ServiceCall };

export interface DialogContext {
  /** Today as YYYY-MM-DD (used as the occurrence date of a new claim). */
  today: string;
}

const MAX_DESCRIPTION = 1000;
const reply = (state: DialogState, replies: ReplyBody[]): Step => ({ kind: 'reply', state, replies });
const call = (c: ServiceCall): Step => ({ kind: 'call', call: c });

/** Interprets one input in the current state. Pure: service calls are returned, not executed. */
export function next(state: DialogState, input: Input, ctx: DialogContext): Step {
  return interrupt(state, input) ?? byState(state, input, ctx);
}

/** Inputs that work from any state (menu, intents, stale buttons). */
function interrupt(state: DialogState, input: Input): Step | undefined {
  switch (input.kind) {
    case 'voice':
      return reply(state, catalog.voiceReceived(input.durationMs));
    case 'choice':
      return fromChoice(input.optionId);
    case 'flow_submit':
      return undefined;
    case 'text': {
      const { intent } = input;
      // While the user writes a free-text description only "cancel" interrupts.
      if (state.name === 'claim.awaiting_description') {
        return intent.name === 'cancel' ? reply(IDLE, catalog.menu()) : undefined;
      }
      switch (intent.name) {
        case 'cancel':
        case 'greeting':
        case 'help':
          return reply(IDLE, catalog.menu());
        case 'quote':
          return startQuote();
        case 'policies':
          return intent.entities.apolice
            ? viewPolicy(intent.entities.apolice)
            : startPolicies(intent.entities.cpf);
        case 'claim':
          return startClaim(intent.entities.cpf);
        case 'claim_status':
          return startClaimStatus(intent.entities.protocolo);
        case 'location':
          return reply(IDLE, catalog.branchLocation());
        case 'unknown':
          return undefined;
      }
    }
  }
}

function fromChoice(id: string): Step | undefined {
  switch (id) {
    case 'menu':
      return reply(IDLE, catalog.menu());
    case 'menu.quote':
      return startQuote();
    case 'menu.policies':
      return startPolicies();
    case 'menu.claim':
      return startClaim();
  }
  const [prefix, ...rest] = id.split(':');
  const value = rest.join(':');
  switch (prefix) {
    case 'policy':
      return isPolicyNumber(value) ? viewPolicy(value) : reply(IDLE, catalog.unknown());
    case 'policy.second_copy':
      return isPolicyNumber(value) ? secondCopy(value) : reply(IDLE, catalog.unknown());
    case 'policy.claim':
    case 'claimpolicy':
      return isPolicyNumber(value)
        ? reply({ name: 'claim.awaiting_type', apolice: value }, catalog.claimTypeChoices(value))
        : reply(IDLE, catalog.unknown());
    default:
      return undefined;
  }
}

function byState(state: DialogState, input: Input, ctx: DialogContext): Step {
  switch (state.name) {
    case 'idle':
      return reply(IDLE, catalog.unknown());

    case 'quote.awaiting_flow':
      if (input.kind === 'flow_submit' && input.flowId === 'cotacao') {
        const parsed = parseQuoteSubmit(input.data);
        if (!parsed.ok) return reply(state, catalog.quoteInvalid());
        return call({
          op: 'createQuote',
          request: parsed.value,
          then: (r) =>
            r.ok
              ? reply(IDLE, catalog.quoteResult(r.value))
              : failure(r.error, state, catalog.invalidData()),
        });
      }
      return reply(state, catalog.quoteFlow());

    case 'policies.awaiting_cpf': {
      const cpf = cpfFrom(input);
      return cpf ? startPolicies(cpf) : reply(state, catalog.invalidCpf());
    }

    case 'policies.awaiting_choice': {
      const numero = apoliceFrom(input, state.numeros);
      return numero ? viewPolicy(numero) : reply(state, catalog.pickAnOption());
    }

    case 'claim.awaiting_cpf': {
      const cpf = cpfFrom(input);
      return cpf ? startClaim(cpf) : reply(state, catalog.invalidCpf());
    }

    case 'claim.awaiting_policy': {
      const numero = apoliceFrom(input, state.numeros);
      return numero
        ? reply({ name: 'claim.awaiting_type', apolice: numero }, catalog.claimTypeChoices(numero))
        : reply(state, catalog.pickAnOption());
    }

    case 'claim.awaiting_type': {
      if (input.kind === 'choice' && input.optionId.startsWith('claim.type:')) {
        const tipo = CLAIM_TYPES.find((t) => `claim.type:${t}` === input.optionId);
        if (tipo) {
          return reply(
            { name: 'claim.awaiting_description', apolice: state.apolice, tipo },
            catalog.askClaimDescription(),
          );
        }
      }
      return reply(state, catalog.claimTypeChoices(state.apolice));
    }

    case 'claim.awaiting_description': {
      if (input.kind !== 'text') return reply(state, catalog.askClaimDescription());
      const descricao = input.text.trim();
      if (descricao.length === 0) return reply(state, catalog.askClaimDescription());
      if (descricao.length > MAX_DESCRIPTION) return reply(state, catalog.descriptionTooLong());
      return call({
        op: 'openClaim',
        request: {
          apoliceNumero: state.apolice,
          tipo: state.tipo,
          dataOcorrencia: ctx.today,
          descricao,
        },
        then: (r) => {
          if (r.ok) return reply(IDLE, catalog.claimOpened(r.value));
          if (r.error === 'conflict') return reply(IDLE, catalog.claimRejected());
          return failure(r.error, state, catalog.notFound('policy'));
        },
      });
    }

    case 'claim_status.awaiting_protocol': {
      const protocolo = protocolFrom(input);
      return protocolo ? viewClaim(protocolo) : reply(state, catalog.askClaimProtocol());
    }
  }
}

function startQuote(): Step {
  return reply({ name: 'quote.awaiting_flow' }, catalog.quoteFlow());
}

function startPolicies(cpf?: string): Step {
  if (!cpf) return reply({ name: 'policies.awaiting_cpf' }, catalog.askCpf('policies'));
  const keep: DialogState = { name: 'policies.awaiting_cpf' };
  return call({
    op: 'listPolicies',
    cpf,
    then: (r) => {
      if (!r.ok) return failure(r.error, keep, catalog.notFound('policy'));
      if (r.value.length === 0) return reply(IDLE, catalog.noPolicies());
      const shown = r.value.slice(0, 3);
      return reply(
        { name: 'policies.awaiting_choice', numeros: shown.map((p) => p.numero) },
        catalog.policyChoices(r.value, 'policy'),
      );
    },
  });
}

function viewPolicy(numero: string): Step {
  if (!isPolicyNumber(numero)) return reply(IDLE, catalog.unknown());
  return call({
    op: 'getPolicy',
    numero,
    then: (r) =>
      r.ok ? reply(IDLE, catalog.policyDetail(r.value)) : failure(r.error, IDLE, catalog.notFound('policy')),
  });
}

function secondCopy(numero: string): Step {
  return call({
    op: 'secondCopy',
    numero,
    then: (r) => {
      if (r.ok) return reply(IDLE, catalog.secondCopy(r.value));
      if (r.error === 'conflict') return reply(IDLE, catalog.secondCopyRejected());
      return failure(r.error, IDLE, catalog.notFound('policy'));
    },
  });
}

function startClaim(cpf?: string): Step {
  if (!cpf) return reply({ name: 'claim.awaiting_cpf' }, catalog.askCpf('claim'));
  const keep: DialogState = { name: 'claim.awaiting_cpf' };
  return call({
    op: 'listPolicies',
    cpf,
    then: (r) => {
      if (!r.ok) return failure(r.error, keep, catalog.notFound('policy'));
      const active = r.value.filter((p) => p.status === 'ATIVA');
      if (active.length === 0) return reply(IDLE, catalog.noActivePolicies());
      const [only] = active;
      if (active.length === 1 && only) {
        return reply(
          { name: 'claim.awaiting_type', apolice: only.numero },
          catalog.claimTypeChoices(only.numero),
        );
      }
      const shown = active.slice(0, 3);
      return reply(
        { name: 'claim.awaiting_policy', numeros: shown.map((p) => p.numero) },
        catalog.policyChoices(active, 'claimpolicy'),
      );
    },
  });
}

function startClaimStatus(protocolo?: string): Step {
  const normalized = protocolo ? normalizeProtocol(protocolo) : undefined;
  return normalized
    ? viewClaim(normalized)
    : reply({ name: 'claim_status.awaiting_protocol' }, catalog.askClaimProtocol());
}

function viewClaim(protocolo: string): Step {
  return call({
    op: 'getClaim',
    protocolo,
    then: (r) =>
      r.ok ? reply(IDLE, catalog.claimDetail(r.value)) : failure(r.error, IDLE, catalog.notFound('claim')),
  });
}

/** `unavailable` keeps the current state so the user can simply repeat the step. */
function failure(f: ServiceFailure, keep: DialogState, notFoundReply: ReplyBody[]): Step {
  switch (f) {
    case 'unavailable':
      return reply(keep, catalog.serviceUnavailable());
    case 'not_found':
      return reply(IDLE, notFoundReply);
    case 'conflict':
      return reply(IDLE, catalog.conflict());
    case 'invalid':
      return reply(IDLE, catalog.invalidData());
  }
}

const cpfFrom = (input: Input): string | undefined =>
  input.kind === 'text' ? (input.intent.entities.cpf ?? normalizeCpf(input.text)) : undefined;

function apoliceFrom(input: Input, allowed: string[]): string | undefined {
  if (input.kind === 'choice') {
    const [prefix, value] = input.optionId.split(':');
    return (prefix === 'policy' || prefix === 'claimpolicy') && value && allowed.includes(value)
      ? value
      : undefined;
  }
  if (input.kind === 'text') {
    const candidate = input.intent.entities.apolice;
    return candidate && allowed.includes(candidate) ? candidate : undefined;
  }
  return undefined;
}

const protocolFrom = (input: Input): string | undefined =>
  input.kind === 'text'
    ? (normalizeProtocol(input.intent.entities.protocolo ?? '') ?? normalizeProtocol(input.text))
    : undefined;
```

```ts
import type { UnsequencedServerEvent } from '@seguradora/protocol';

/**
 * Everything one turn (one `event.id`) produced. The turn writes into it; any number of
 * consumers read it, including ones that arrive while the turn is still running or after it
 * has finished. That is what makes a repeated `event.id` idempotent.
 */
export class TurnRecord {
  private readonly events: UnsequencedServerEvent[] = [];
  private finished = false;
  private waiters: Array<() => void> = [];

  get isFinished(): boolean {
    return this.finished;
  }

  get size(): number {
    return this.events.length;
  }

  push(event: UnsequencedServerEvent): void {
    if (this.finished) throw new Error('TurnRecord: cannot push after finish');
    this.events.push(event);
    this.wake();
  }

  finish(): void {
    this.finished = true;
    this.wake();
  }

  async *stream(): AsyncGenerator<UnsequencedServerEvent> {
    let index = 0;
    for (;;) {
      for (let e = this.events[index]; e !== undefined; e = this.events[index]) {
        index++;
        yield e;
      }
      if (this.finished) return;
      await new Promise<void>((resolve) => this.waiters.push(resolve));
    }
  }

  private wake(): void {
    const waiting = this.waiters;
    this.waiters = [];
    for (const resolve of waiting) resolve();
  }
}

/** Bounded map of event id → record (oldest ids are forgotten first). */
export class TurnLog {
  private readonly records = new Map<string, TurnRecord>();

  constructor(private readonly capacity: number) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`TurnLog: capacity must be an integer >= 1, got ${capacity}`);
    }
  }

  begin(eventId: string): { record: TurnRecord; created: boolean } {
    const existing = this.records.get(eventId);
    if (existing) return { record: existing, created: false };
    const record = new TurnRecord();
    this.records.set(eventId, record);
    if (this.records.size > this.capacity) {
      const oldest = this.records.keys().next().value;
      if (oldest !== undefined) this.records.delete(oldest);
    }
    return { record, created: true };
  }
}
```

```ts
import type { ChatbotRequest, UnsequencedServerEvent } from '@seguradora/protocol';
import { next, type Input, type ServiceCall, type Step } from '../domain/dialog';
import type { ReplyBody } from '../domain/reply';
import type { TurnLog, TurnRecord } from '../domain/turn-log';
import type {
  CallContext,
  Clock,
  DialogStore,
  IdGenerator,
  LlmProvider,
  Logger,
  ServicesPort,
  TurnRunner,
} from './ports';

export interface HandleTurnDeps {
  llm: LlmProvider;
  services: ServicesPort;
  dialogs: DialogStore;
  turns: TurnLog;
  newId: IdGenerator;
  now: Clock;
  logger: Logger;
}

const MAX_CALLS_PER_TURN = 5;
const INTERNAL_ERROR_MESSAGE = 'Não foi possível processar sua mensagem. Tente novamente.';

/** Never log anything the user typed or received from a service: only the error type. */
const describeError = (error: unknown): { name: string } => ({
  name: error instanceof Error ? error.name : 'UnknownError',
});

/**
 * One turn = one user event. The first call for an `event.id` runs the turn in the background
 * and every call (first or repeated) reads the events from the `TurnRecord`, so the same id
 * never executes twice and always yields the same events.
 */
export class HandleTurn implements TurnRunner {
  constructor(private readonly d: HandleTurnDeps) {}

  run(request: ChatbotRequest): AsyncGenerator<UnsequencedServerEvent> {
    const { record, created } = this.d.turns.begin(request.event.id);
    if (created) void this.execute(request, record);
    return record.stream();
  }

  /** Never rejects: failures become an `error` event. Always finishes the record. */
  private async execute(request: ChatbotRequest, record: TurnRecord): Promise<void> {
    const emit = (body: ReplyBody) => record.push(this.envelope(request, body));
    const log = { sessionId: request.sessionId, correlationId: request.correlationId };
    try {
      if (request.event.type !== 'user.flow_data_exchange') {
        emit({ type: 'status.typing', payload: { state: 'start' } });
        const input = await this.toInput(request);
        if (input) {
          const step = await this.decide(request, input);
          this.d.dialogs.set(request.sessionId, step.state);
          emit({ type: 'status.typing', payload: { state: 'stop' } });
          for (const body of step.replies) emit(body);
        } else {
          emit({ type: 'status.typing', payload: { state: 'stop' } });
        }
      }
    } catch (error) {
      this.d.logger.error({ ...log, err: describeError(error) }, 'turn failed');
      emit({
        type: 'error',
        payload: { code: 'internal_error', message: INTERNAL_ERROR_MESSAGE },
      });
    } finally {
      record.finish();
    }
  }

  private async toInput(request: ChatbotRequest): Promise<Input | undefined> {
    const event = request.event;
    switch (event.type) {
      case 'user.text':
        return {
          kind: 'text',
          text: event.payload.text,
          intent: await this.d.llm.classify(event.payload.text),
        };
      case 'user.quick_reply':
        return { kind: 'choice', optionId: event.payload.optionId };
      case 'user.flow_submit':
        return { kind: 'flow_submit', flowId: event.payload.flowId, data: event.payload.data };
      case 'user.voice':
        return { kind: 'voice', durationMs: event.payload.durationMs };
      default:
        return undefined;
    }
  }

  /** Runs the dialog until it produces a reply, executing the service calls it asks for. */
  private async decide(
    request: ChatbotRequest,
    input: Input,
  ): Promise<Extract<Step, { kind: 'reply' }>> {
    const ctx: CallContext = {
      correlationId: request.correlationId,
      idempotencyKey: request.event.id,
    };
    const state = this.d.dialogs.get(request.sessionId);
    let step = next(state, input, { today: new Date(this.d.now()).toISOString().slice(0, 10) });
    for (let calls = 0; step.kind === 'call'; calls++) {
      if (calls >= MAX_CALLS_PER_TURN) throw new Error('too many service calls in one turn');
      step = await this.runCall(step.call, ctx);
    }
    return step;
  }

  private async runCall(c: ServiceCall, ctx: CallContext): Promise<Step> {
    const s = this.d.services;
    switch (c.op) {
      case 'listPolicies':
        return c.then(await s.listPolicies(c.cpf, ctx));
      case 'getPolicy':
        return c.then(await s.getPolicy(c.numero, ctx));
      case 'secondCopy':
        return c.then(await s.secondCopy(c.numero, ctx));
      case 'createQuote':
        return c.then(await s.createQuote(c.request, ctx));
      case 'openClaim':
        return c.then(await s.openClaim(c.request, ctx));
      case 'getClaim':
        return c.then(await s.getClaim(c.protocolo, ctx));
    }
  }

  private envelope(request: ChatbotRequest, body: ReplyBody): UnsequencedServerEvent {
    return {
      v: 1,
      id: this.d.newId(),
      sessionId: request.sessionId,
      correlationId: request.correlationId,
      ts: new Date(this.d.now()).toISOString(),
      ...body,
    } as UnsequencedServerEvent;
  }
}
```

```ts
import type { LlmProvider } from '../application/ports';
import type { Intent, IntentName } from '../domain/dialog';
import { normalizeProtocol } from '../domain/identifiers';

const normalize = (s: string): string =>
  s
    .normalize('NFD')
    .replace(/\p{Diacritic}/gu, '')
    .toLowerCase();

/** Ordered: the first matching rule wins (specific intents before the generic ones). */
const RULES: Array<[IntentName, RegExp]> = [
  ['cancel', /\b(cancelar|voltar|sair|parar)\b/],
  ['claim_status', /\bsinistro\b.*\b(status|andamento|consultar|acompanhar|situacao)\b|\b(status|andamento|consultar|acompanhar|situacao)\b.*\bsinistro\b/],
  ['claim', /\b(sinistro|bati|colisao|roubo|roubaram|furto|furtaram|acidente|incendio)\b/],
  ['quote', /\b(cotacao|cotar|simular|simulacao|orcamento|quanto custa|preco)\b/],
  ['policies', /\b(apolice|apolices|segunda via|2a via|meu seguro|meus seguros)\b/],
  ['location', /\b(agencia|filial|endereco|onde fica|localizacao|escritorio)\b/],
  ['help', /\b(ajuda|help|o que voce faz|opcoes)\b/],
  ['greeting', /\b(oi|ola|bom dia|boa tarde|boa noite|menu|inicio|comecar)\b/],
];

const CPF_RE = /(?<![\d.\-])(\d{3}\.?\d{3}\.?\d{3}-?\d{2})(?![\d])/;
const POLICY_RE = /\bap-?(\d{3,6})\b/i;
const PROTOCOL_RE = /\bsn-?(\d{3,6})\b/i;

/** Deterministic stand-in for an LLM: keyword rules plus entity extraction. */
export class MockLlmProvider implements LlmProvider {
  async classify(text: string): Promise<Intent> {
    const entities: Intent['entities'] = {};
    const cpf = CPF_RE.exec(text)?.[1];
    if (cpf) entities.cpf = cpf.replace(/\D/g, '');
    const apolice = POLICY_RE.exec(text)?.[1];
    if (apolice) entities.apolice = `AP-${apolice}`;
    const protocolo = PROTOCOL_RE.exec(text)?.[1];
    if (protocolo) entities.protocolo = normalizeProtocol(`SN-${protocolo}`) ?? undefined;
    if (entities.protocolo === undefined) delete entities.protocolo;

    const normalized = normalize(text);
    let name: IntentName = 'unknown';
    for (const [candidate, rule] of RULES) {
      if (rule.test(normalized)) {
        name = candidate;
        break;
      }
    }
    if (name === 'unknown') {
      if (entities.protocolo) name = 'claim_status';
      else if (entities.apolice) name = 'policies';
    }
    return { name, entities };
  }
}
```

```ts
import { withTimeout } from '@seguradora/resilience';
import type { LlmProvider, Logger } from '../application/ports';
import type { Intent } from '../domain/dialog';

const INTENT_NAMES = new Set([
  'greeting',
  'quote',
  'policies',
  'claim',
  'claim_status',
  'location',
  'help',
  'cancel',
  'unknown',
]);

export interface GuardedLlmOptions {
  timeoutMs: number;
  /** Longer inputs are truncated before they reach the provider (cost and abuse control). */
  maxInputChars: number;
  logger: Logger;
}

const FALLBACK: Intent = { name: 'unknown', entities: {} };

const isIntent = (v: unknown): v is Intent =>
  typeof v === 'object' &&
  v !== null &&
  typeof (v as Intent).name === 'string' &&
  INTENT_NAMES.has((v as Intent).name) &&
  typeof (v as Intent).entities === 'object' &&
  (v as Intent).entities !== null;

/** Wraps any provider with input truncation, a timeout and a safe fallback. */
export class GuardedLlmProvider implements LlmProvider {
  constructor(
    private readonly inner: LlmProvider,
    private readonly o: GuardedLlmOptions,
  ) {}

  async classify(text: string): Promise<Intent> {
    try {
      const result = await withTimeout(
        () => this.inner.classify(text.slice(0, this.o.maxInputChars)),
        this.o.timeoutMs,
      );
      if (isIntent(result)) return result;
      this.o.logger.warn({ reason: 'malformed' }, 'llm returned an invalid intent');
    } catch (error) {
      // Never log the input or the provider message: only the kind of failure.
      this.o.logger.warn(
        { reason: error instanceof Error ? error.name : 'UnknownError' },
        'llm failed; falling back to unknown',
      );
    }
    return FALLBACK;
  }
}
```

```ts
import type { Clock, DialogStore } from '../application/ports';
import { IDLE, type DialogState } from '../domain/dialog';

export interface DialogStoreOptions {
  capacity: number;
  ttlMs: number;
  now?: Clock;
}

interface Entry {
  state: DialogState;
  updated: number;
}

export class InMemoryDialogStore implements DialogStore {
  private readonly entries = new Map<string, Entry>();
  private readonly now: Clock;

  constructor(private readonly o: DialogStoreOptions) {
    if (!Number.isInteger(o.capacity) || o.capacity < 1) {
      throw new RangeError(`InMemoryDialogStore: capacity must be an integer >= 1, got ${o.capacity}`);
    }
    this.now = o.now ?? Date.now;
  }

  get(sessionId: string): DialogState {
    const entry = this.entries.get(sessionId);
    if (!entry) return IDLE;
    if (this.now() - entry.updated > this.o.ttlMs) {
      this.entries.delete(sessionId);
      return IDLE;
    }
    return entry.state;
  }

  set(sessionId: string, state: DialogState): void {
    this.entries.delete(sessionId);
    this.entries.set(sessionId, { state, updated: this.now() });
    if (this.entries.size > this.o.capacity) {
      const oldest = this.entries.keys().next().value;
      if (oldest !== undefined) this.entries.delete(oldest);
    }
  }

  /** Removes expired sessions; returns how many were removed. */
  sweep(): number {
    const t = this.now();
    let removed = 0;
    for (const [id, entry] of this.entries) {
      if (t - entry.updated > this.o.ttlMs) {
        this.entries.delete(id);
        removed++;
      }
    }
    return removed;
  }
}
```

```ts
import { Bulkhead, CircuitBreaker, createPolicy, TimeoutError } from '@seguradora/resilience';

/** A service answered with an HTTP status that the policy treats as an upstream problem. */
export class ServiceHttpError extends Error {
  constructor(readonly status: number) {
    super(`Service responded with HTTP ${status}`);
    this.name = 'ServiceHttpError';
  }
}

const RETRYABLE_STATUS = new Set([502, 503, 504]);

/** undici wraps real network failures (DNS, refused, reset) as `TypeError('fetch failed')`. */
const isNetworkError = (error: unknown): boolean =>
  error instanceof TypeError && error.message === 'fetch failed';

/** Safe to repeat: GETs are idempotent and POSTs carry an Idempotency-Key. */
export const isSafeToRetry = (error: unknown): boolean =>
  error instanceof TimeoutError ||
  isNetworkError(error) ||
  (error instanceof ServiceHttpError && RETRYABLE_STATUS.has(error.status));

/** Problems of the upstream itself (not of the request) count towards the circuit breaker. */
export const isUpstreamFailure = (error: unknown): boolean =>
  error instanceof TimeoutError ||
  isNetworkError(error) ||
  (error instanceof ServiceHttpError && (error.status >= 500 || error.status === 429));

export interface ServicePolicyOptions {
  timeoutMs: number;
  retries: number;
  retryBaseDelayMs: number;
  retryMaxDelayMs: number;
  breakerFailureThreshold: number;
  breakerResetMs: number;
  bulkheadMaxConcurrent: number;
  bulkheadMaxQueue: number;
  now?: () => number;
  sleep?: (ms: number) => Promise<void>;
}

/** bulkhead → circuit breaker → retry → timeout; create one per service. */
export function createServicePolicy(o: ServicePolicyOptions) {
  return createPolicy({
    timeoutMs: o.timeoutMs,
    retry: {
      retries: o.retries,
      baseDelayMs: o.retryBaseDelayMs,
      maxDelayMs: o.retryMaxDelayMs,
      shouldRetry: isSafeToRetry,
      ...(o.sleep ? { sleep: o.sleep } : {}),
    },
    breaker: new CircuitBreaker({
      failureThreshold: o.breakerFailureThreshold,
      resetTimeoutMs: o.breakerResetMs,
      isFailure: isUpstreamFailure,
      ...(o.now ? { now: o.now } : {}),
    }),
    bulkhead: new Bulkhead({
      maxConcurrent: o.bulkheadMaxConcurrent,
      maxQueue: o.bulkheadMaxQueue,
    }),
  });
}
```

```ts
import { err, ok, type Result } from '@seguradora/protocol';
import type { z } from 'zod';
import type { CallContext, Logger } from '../../application/ports';
import type { ServiceFailure } from '../../domain/models';
import { ServiceHttpError } from './services-policy';

export interface HttpJsonClientOptions {
  baseUrl: string;
  /** Result of `createServicePolicy`: wraps the whole exchange, including reading the body. */
  policy: <T>(fn: (signal: AbortSignal) => Promise<T>) => Promise<T>;
  logger: Logger;
  fetchImpl?: typeof fetch;
}

export interface JsonCall<T> {
  method: 'GET' | 'POST';
  path: string;
  query?: Record<string, string>;
  body?: unknown;
  schema: z.ZodType<T>;
  ctx: CallContext;
}

const HEADER_SAFE = /^[\x21-\x7e]{1,128}$/;

/** Talks JSON to one internal service and turns every outcome into `Result<T, ServiceFailure>`. */
export class HttpJsonClient {
  private readonly fetchImpl: typeof fetch;

  constructor(private readonly o: HttpJsonClientOptions) {
    this.fetchImpl = o.fetchImpl ?? fetch;
  }

  async call<T>(c: JsonCall<T>): Promise<Result<T, ServiceFailure>> {
    const url = new URL(c.path, this.o.baseUrl);
    for (const [k, v] of Object.entries(c.query ?? {})) url.searchParams.set(k, v);

    const headers: Record<string, string> = { accept: 'application/json' };
    if (HEADER_SAFE.test(c.ctx.correlationId)) headers['x-correlation-id'] = c.ctx.correlationId;
    if (c.method === 'POST') {
      headers['content-type'] = 'application/json';
      if (HEADER_SAFE.test(c.ctx.idempotencyKey)) headers['idempotency-key'] = c.ctx.idempotencyKey;
    }

    let outcome: { status: number; text: string };
    try {
      outcome = await this.o.policy(async (signal) => {
        const res = await this.fetchImpl(url, {
          method: c.method,
          headers,
          ...(c.body !== undefined ? { body: JSON.stringify(c.body) } : {}),
          signal,
        });
        if (res.status >= 500 || res.status === 429) {
          // Best effort: free the connection; the status is what matters.
          void res.body?.cancel().catch(() => undefined);
          throw new ServiceHttpError(res.status);
        }
        return { status: res.status, text: await res.text() };
      });
    } catch (error) {
      // Never log the URL (it can carry a cpf) nor the message: only the kind of failure.
      this.o.logger.warn(
        { op: `${c.method} ${c.path.replace(/\/[^/]*$/, '/…')}`, reason: error instanceof Error ? error.name : 'UnknownError' },
        'service call failed',
      );
      return err('unavailable');
    }

    if (outcome.status === 404) return err('not_found');
    if (outcome.status === 409) return err('conflict');
    if (outcome.status === 400 || outcome.status === 422) return err('invalid');
    if (outcome.status < 200 || outcome.status >= 300) return err('unavailable');

    let json: unknown;
    try {
      json = JSON.parse(outcome.text);
    } catch {
      this.o.logger.warn({ status: outcome.status }, 'service returned invalid JSON');
      return err('unavailable');
    }
    const parsed = c.schema.safeParse(json);
    if (!parsed.success) {
      this.o.logger.warn(
        { status: outcome.status, paths: parsed.error.issues.slice(0, 5).map((i) => i.path.join('.')) },
        'service response does not match the contract',
      );
      return err('unavailable');
    }
    return ok(parsed.data);
  }
}
```

```ts
import type { CallContext, ServicesPort } from '../../application/ports';
import { isClaimProtocol, isPolicyNumber } from '../../domain/identifiers';
import type { ClaimRequest, QuoteRequest } from '../../domain/models';
import type { HttpJsonClient } from './http-json';
import {

  PolicySchema,

  cotacao: HttpJsonClient;
  apolice: HttpJsonClient;
  sinistro: HttpJsonClient;

const invalid = () => Promise.resolve(err('invalid' as const));

/** Implements `ServicesPort` over the three internal services (see the services contract doc). */
export class HttpServices implements ServicesPort {
  constructor(private readonly c: HttpServicesClients) {}

  async listPolicies(cpf: string, ctx: CallContext) {
    if (!/^\d{11}$/.test(cpf)) return invalid();

      method: 'GET',
      path: '/v1/apolices',
      query: { cpf },

      ctx,

    if (!isPolicyNumber(numero)) return invalid();
    return this.c.apolice.call({
      method: 'GET',
      path: `/v1/apolices/${encodeURIComponent(numero)}`,
      schema: PolicySchema,
      ctx,
    });
  }

    if (!isPolicyNumber(numero)) return invalid();
    return this.c.apolice.call({
      method: 'GET',
      path: `/v1/apolices/${encodeURIComponent(numero)}/segunda-via`,
      schema: SecondCopySchema,
      ctx,
    });

    return this.c.cotacao.call({
      method: 'POST',
      path: '/v1/cotacoes',
      body: {
        produto: request.produto,
        cliente: request.cliente,
        dados: request.dados,
        coberturas: request.coberturas,
      },
      schema: QuoteSchema,
      ctx,
    });

    if (!isPolicyNumber(request.apoliceNumero)) return invalid();

      method: 'POST',

        apoliceNumero: request.apoliceNumero,
        tipo: request.tipo,
        dataOcorrencia: request.dataOcorrencia,
        descricao: request.descricao,
      },

      ctx,
    });

      method: 'GET',
      path: `/v1/sinistros/${encodeURIComponent(protocolo)}`,
      schema: ClaimSchema,
      ctx,
    });
```

```ts
import {
  ChatbotRequestSchema,
  LIMITS,
  serializeChatbotLine,
  type ErrorCode,
} from '@seguradora/protocol';
import Fastify, {
  type FastifyBaseLogger,
  type FastifyError,
  type FastifyInstance,
  type FastifyReply,
} from 'fastify';
import type { Logger as PinoLogger } from 'pino';
import type { TurnRunner } from '../../application/ports';

export interface AppDeps {
  turns: TurnRunner;
  logger: PinoLogger;
}

function describeStatus(status: number): { code: ErrorCode; message: string } {
  if (status === 413) return { code: 'payload_too_large', message: 'Request too large.' };
  if (status === 429) return { code: 'rate_limited', message: 'Too many requests.' };
  if (status === 401 || status === 403) return { code: 'unauthorized', message: 'Not authorized.' };
  if (status >= 400 && status < 500) return { code: 'invalid_schema', message: 'Invalid request.' };
  return { code: 'internal_error', message: 'Internal error.' };
}

/** Message built from the path and code of the first issue only: never echoes the input. */
const summarizeIssue = (error: { issues: Array<{ path: PropertyKey[]; code: string }> }) => {
  const issue = error.issues[0];
  if (!issue) return 'Invalid request.';
  const where = issue.path.map(String).join('.') || 'request';
  return `Invalid request at ${where} (${issue.code}).`.slice(0, 200);
};

/** Waits until the response can take more data, or the client is gone. */
const drained = (raw: NodeJS.WritableStream & { destroyed?: boolean }) =>
  new Promise<void>((resolve) => {
    raw.once('drain', resolve);
    raw.once('close', resolve);
  });

export async function buildApp({ turns, logger }: AppDeps): Promise<FastifyInstance> {
  const app: FastifyInstance = Fastify({
    loggerInstance: logger as FastifyBaseLogger,
    // The request wraps one client event, so allow twice the event limit.
    bodyLimit: LIMITS.maxEventBytes * 2,
    // Streams are internal and short; do not let idle or pre-opened sockets delay shutdown.
    forceCloseConnections: true,
  });

  // Only JSON is accepted (Fastify also parses text/plain by default).
  app.removeContentTypeParser('text/plain');

  const deny = (reply: FastifyReply, status: number, code: ErrorCode, message: string) =>
    reply.status(status).send({ error: { code, message } });

  app.setErrorHandler((error: FastifyError, request, reply) => {
    const status = typeof error.statusCode === 'number' && error.statusCode >= 400 ? error.statusCode : 500;
    if (status >= 500) request.log.error({ err: error }, 'unhandled error');
    const { code, message } = describeStatus(status);
    return deny(reply, status, code, message);
  });
  app.setNotFoundHandler((_request, reply) => deny(reply, 404, 'invalid_schema', 'Route not found.'));

  app.get('/health', async () => ({ status: 'ok' }));
  app.get('/ready', async () => ({ status: 'ready' }));

  app.post('/v1/chat/events', async (request, reply) => {
    const parsed = ChatbotRequestSchema.safeParse(request.body);
    if (!parsed.success) return deny(reply, 400, 'invalid_schema', summarizeIssue(parsed.error));

    // Headers first: the gateway's connect timeout only covers the time until the headers.
    reply.hijack();
    const raw = reply.raw;
    raw.writeHead(200, {
      'content-type': 'application/x-ndjson',
      'cache-control': 'no-store',
      'x-content-type-options': 'nosniff',
    });
    raw.flushHeaders();

    let clientGone = false;
    raw.on('close', () => {
      clientGone = true;
    });

    try {
      for await (const event of turns.run(parsed.data)) {
        if (clientGone) break; // the turn keeps running; only the writing stops
        if (!raw.write(serializeChatbotLine(event))) await drained(raw);
      }
    } catch (error) {
      request.log.error(
        { err: error instanceof Error ? { name: error.name } : { name: 'UnknownError' } },
        'turn stream failed after the headers were sent',
      );
    } finally {
      if (!raw.writableEnded) raw.end();
    }
  });

  return app;
}
```

```ts
  overrides: ChatbotOverrides = {},

  const now: Clock = overrides.now ?? (() => Date.now());

      retryMaxDelayMs: config.SERVICE_RETRY_MAX_MS,
      breakerFailureThreshold: config.BREAKER_FAILURE_THRESHOLD,
      breakerResetMs: config.BREAKER_RESET_MS,
      bulkheadMaxConcurrent: config.BULKHEAD_MAX_CONCURRENT,
      bulkheadMaxQueue: config.BULKHEAD_MAX_QUEUE,
    });
  const client = (baseUrl: string) => new HttpJsonClient({ baseUrl, policy: policy(), logger });

  const services =
    overrides.services ??
    new HttpServices({
      cotacao: client(config.COTACAO_URL),
      apolice: client(config.APOLICE_URL),
      sinistro: client(config.SINISTRO_URL),
    });

  const llm =
    overrides.llm ??
    new GuardedLlmProvider(new MockLlmProvider(), {
      timeoutMs: config.LLM_TIMEOUT_MS,
      maxInputChars: config.LLM_MAX_INPUT_CHARS,
      logger,
    });

  const turns = new HandleTurn({
    llm,
    services,
    dialogs,
    turns: new TurnLog(config.TURN_LOG_CAPACITY),
    newId,
    now,
    logger,
  });

  const app = await buildApp({ turns, logger });
  return { app, dialogs };
}
```

```ts
export interface TurnResult {
  status: number;
  headers: Headers;
  /** Time until the response headers arrived (ms). */
  headersAfterMs: number;
  events: UnsequencedServerEvent[];
}

/** POSTs a request like the gateway does and parses every NDJSON line with the protocol schema. */
export async function turn(url: string, request: ChatbotRequest): Promise<TurnResult> {
  const started = Date.now();
  const res = await fetch(`${url}/v1/chat/events`, {
    method: 'POST',
    headers: {
      'content-type': 'application/json',
      accept: 'application/x-ndjson',
      'x-correlation-id': request.correlationId,
    },
    body: JSON.stringify(request),
  });
  const headersAfterMs = Date.now() - started;
  const body = await res.text();
  const events: UnsequencedServerEvent[] = [];
  for (const line of body.split('\n')) {
    if (!line) continue;
    const parsed = parseChatbotLine(line);
    if (!parsed.ok) throw new Error(`chatbot sent an invalid NDJSON line: ${parsed.error.message}`);
    events.push(parsed.value);
  }
  return { status: res.status, headers: res.headers, headersAfterMs, events };
}

export const replies = (events: UnsequencedServerEvent[]) =>

  events.flatMap((e) => (e.type === 'message.text' ? [e.payload.text] : [])).join(' | ');
```
