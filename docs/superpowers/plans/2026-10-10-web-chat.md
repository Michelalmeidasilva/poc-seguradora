# Web Chat: Plano de Implementação (Plano 4 de 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `apps/web` (parte de chat): a interface React + Vite que reproduz o layout do WhatsApp (bolhas, ticks, tema claro/escuro), conversa com o gateway por SSE + POST com reenvio idempotente e renderiza todos os tipos de mensagem do protocolo (texto com formatação, voz, código, location, template, carrossel, quick replies, digitando, aviso) e a mensagem que abre um Flow (o motor de Flows é o Plano 5).

**Architecture:** Feature-sliced em TypeScript estrito. A camada `transport/` é TypeScript puro, sem React: um parser SSE incremental, um `SseClient` baseado em `fetch` (reconexão com backoff e `Last-Event-ID`, vigia de heartbeat) e um `ChatClient` (sessão, fila de saída com reenvio idempotente, `user.ack`). A camada `chat/` guarda o estado em um reducer puro, a persistência em `sessionStorage`, a trava de aba única (Web Locks) e o hook `useChat`. A camada `renderers/` mapeia cada evento do servidor para um componente. A camada `ui/` traz os tokens de design do WhatsApp, os ícones e a bolha. O gateway é acessado **no mesmo origin** (`/v1`): o proxy do Vite em desenvolvimento e o nginx em produção, o que evita cookies de terceiros.

**Tech Stack:** React 19, Vite 5, Vitest 2 (jsdom) + Testing Library, Playwright, CSS puro com variáveis, `@seguradora/protocol` (validação dos eventos que chegam), nginx para o contêiner.

**Specs:**
- `docs/superpowers/specs/2026-10-10-whatsapp-chatbot-poc-design.md` (seções 3, 4, 14)
- `docs/superpowers/specs/2026-10-10-gateway-chatbot-contract.md` (eventos que o chatbot emite e o que cada um significa)
- Contrato HTTP/SSE do gateway: `docs/superpowers/plans/2026-10-10-gateway.md` (rotas `POST /v1/session`, `POST /v1/events`, `GET /v1/stream`; códigos de erro; semântica de `seq`, replay e `status.delivered`)

Código existente que este plano consome (já na `master`): `@seguradora/protocol` (`parseServerEvent`, `ServerEvent`, `ClientEvent`, `ErrorCode`, `LIMITS`).

**Execução:** em uma branch nova `feat/web-chat`, de preferência em um `git worktree` próprio, partindo da `master`.

## Decisões deste plano (tomadas por mim; revise e vete antes de executar)

1. **Mesmo origin para a API.** A web chama `/v1/...` sem domínio. Em desenvolvimento, o proxy do Vite repassa ao gateway (`VITE_DEV_GATEWAY_URL`, padrão `http://localhost:8080`); em produção, o nginx faz o proxy (sem buffer, para o SSE). Assim o cookie `sid` é de primeira parte (`SameSite=Lax`), sem depender de cookies de terceiros.
2. **SSE por `fetch`, não `EventSource`.** Precisamos controlar backoff, `Last-Event-ID`, 401 (sessão nova) e vigia de heartbeat, o que o `EventSource` não permite.
3. **Uma aba ativa por vez** (Web Locks). O gateway substitui o stream anterior da mesma sessão; duas abas com `EventSource` entrariam em ciclo de reconexões. A segunda aba mostra um aviso e um botão «Usar esta aba» (toma o lock).
4. **Histórico sobrevive ao recarregar** via `sessionStorage` (sessionId, `lastSeq` e as últimas 200 mensagens). Ao recarregar, a web tenta o stream com o cookie existente; se vier 401, abre uma sessão nova e avisa.
5. **Voz do usuário fica no navegador.** Não há endpoint de upload no gateway. O áudio gravado toca localmente (blob) e o protocolo recebe um `user.voice` com `mediaId` gerado no cliente. Isso fica registrado como pendência de produto.
6. **A web não envia `user.typing`** (o gateway o descarta de qualquer jeito). Envia `user.ack` com o último `seq` processado (com debounce).
7. **Flows:** este plano só renderiza a mensagem `message.flow` (bolha + botão) e define o contrato `FlowHost`/`OpenFlow`; um host provisório mostra «Formulário disponível em breve». O Plano 5 implementa o motor.
8. **Sem recursos externos:** fontes do sistema, ícones SVG inline, nenhuma CDN. CSP estrita no nginx.
9. **Housekeeping do WORKBOARD:** durante este plano a frente `web-chat` passa a ser dona de `apps/web` inteiro e a linha `web-flows` é removida (o Plano 5 a recria, depois que `web-chat` estiver `done`). Isso evita o conflito de caminhos sobrepostos que o `workboard-check` rejeita.
10. **E2E sem o backend real:** o Playwright usa um gateway simulado (`e2e/mock-gateway.mjs`, Node puro) fiel ao protocolo. O teste de pilha completa (web + gateway + chatbot + serviços) fica para um plano de integração.

## Global Constraints

- Um único repositório git na raiz. Nunca `git init` dentro de `apps/*` ou `packages/*`.
- TypeScript `strict` (com `noUncheckedIndexedAccess`); React 19; Node ≥ 22.12 para as ferramentas; pnpm monorepo.
- Todo evento recebido do gateway é validado com `parseServerEvent` antes de entrar no estado; o que não valida é descartado sem registrar conteúdo.
- **Nunca** usar `dangerouslySetInnerHTML`. Todo texto vindo do servidor é renderizado como texto; links só com `http:`/`https:` e `rel="noopener noreferrer"`; `tel:` só com dígitos, `+`, espaços, parênteses e hífens.
- Nenhum recurso externo (fonte, imagem, script, CDN) carregado pela própria aplicação; imagens de carrossel e áudio vindos do servidor falham com elegância (placeholder).
- Arquitetura feature-sliced verificada pelo `dependency-cruiser`: `transport/` e `chat/model` não importam React; `ui/` não importa `chat/`, `renderers/` nem `transport/`; `renderers/` não importa `transport/`.
- Tema somente por variáveis CSS (tokens); claro/escuro por `prefers-color-scheme` e por `?theme=dark|light`.
- Texto da interface em português do Brasil; identificadores e comentários de código em inglês.
- Nada de `console.*` com conteúdo de mensagem; erros inesperados só pelo nome.
- Commits convencionais; atualizar `CHECKLIST.md` no mesmo commit que conclui o item; reivindicar a frente no `WORKBOARD.md` antes de codar (skill `workboard-protocol`); `prettier --write` pela raiz antes de comitar.

## Review Focus

Entradas que o spec não detalha e que mais provavelmente quebram:

1. **Reconexão sem perder nem duplicar:** depois de uma queda do stream, o `Last-Event-ID` correto é enviado, eventos repetidos (mesmo `seq` ou mesmo `id`) são ignorados e uma lacuna de `seq` gera um único aviso. Testes nas Tarefas 4, 5 e 11.
2. **Reenvio idempotente:** uma mensagem que falhou (`error` com `messageId`) é reenviada com o **mesmo** `id` e não cria uma segunda bolha; o status nunca volta para trás (um `delivered` atrasado não desfaz `failed` de um reenvio posterior, e vice-versa). Testes nas Tarefas 4, 6 e 11.
3. **XSS e URLs:** texto com `<script>`, `javascript:`, `data:` e HTML é exibido como texto; links, imagens, áudio e `tel:` malformados não viram elementos ativos. Testes nas Tarefas 3, 8 e 9.
4. **Duas abas não brigam:** só uma abre o stream; a outra mostra o aviso; «Usar esta aba» assume sem laço de reconexão. Testes nas Tarefas 7 e 11.
5. **Acessibilidade:** a lista de mensagens é uma região `log` que anuncia só o que chega (não o histórico inteiro), botões têm nome acessível, o foco volta ao campo de texto depois de enviar, o carrossel e os botões funcionam por teclado, `prefers-reduced-motion` é respeitado. Testes nas Tarefas 9 e 10.

```ts
    ...(timeZone ? { timeZone } : {}),
  }).format(d);

export function formatTime(iso: string, locale = 'pt-BR', timeZone?: string): string {
  const date = new Date(iso);
  if (Number.isNaN(date.getTime())) return '';
  return new Intl.DateTimeFormat(locale, {
    hour: '2-digit',
    minute: '2-digit',
    hour12: false,
    ...(timeZone ? { timeZone } : {}),
  }).format(date);
}

export function sameDay(a: string, b: string, timeZone?: string): boolean {
  const da = new Date(a);
  const db = new Date(b);
  if (Number.isNaN(da.getTime()) || Number.isNaN(db.getTime())) return false;
  return dayKey(da, 'pt-BR', timeZone) === dayKey(db, 'pt-BR', timeZone);
}

export function formatDay(iso: string, now: Date, locale = 'pt-BR', timeZone?: string): string {
  const date = new Date(iso);
  if (Number.isNaN(date.getTime())) return '';
  const key = dayKey(date, locale, timeZone);
  if (key === dayKey(now, locale, timeZone)) return 'Hoje';
  if (key === dayKey(new Date(now.getTime() - 24 * 60 * 60 * 1000), locale, timeZone)) {
    return 'Ontem';
  }
  return key;
}
```

```ts
export type TextNode =
  | { type: 'text'; value: string }
  | { type: 'bold' | 'italic' | 'strike'; children: TextNode[] }
  | { type: 'mono' | 'block'; value: string }
  | { type: 'link'; href: string; label: string };

type Rule = { kind: 'block' | 'mono' | 'bold' | 'italic' | 'strike'; re: RegExp };

// WhatsApp-style markers: they must hug the marked text and not touch letters or digits.
const RULES: Rule[] = [
  { kind: 'block', re: /```([\s\S]+?)```/u },
  { kind: 'mono', re: /(?<![\p{L}\p{N}`])`(?=\S)([^`\n]+?)(?<=\S)`(?![\p{L}\p{N}`])/u },
  { kind: 'bold', re: /(?<![\p{L}\p{N}*])\*(?=\S)([^*\n]+?)(?<=\S)\*(?![\p{L}\p{N}*])/u },
  { kind: 'italic', re: /(?<![\p{L}\p{N}_])_(?=\S)([^_\n]+?)(?<=\S)_(?![\p{L}\p{N}_])/u },
  { kind: 'strike', re: /(?<![\p{L}\p{N}~])~(?=\S)([^~\n]+?)(?<=\S)~(?![\p{L}\p{N}~])/u },
];

const URL_RE = /https?:\/\/[^\s<>"']+/u;
const TRAILING_PUNCTUATION = /[.,;:!?)\]]+$/u;

interface Found {
  index: number;
  length: number;
  node: TextNode;
}

export function parseFormatting(text: string): TextNode[] {
  const nodes: TextNode[] = [];
  let rest = text;

  while (rest.length > 0) {
    let best: Found | undefined;

    for (const rule of RULES) {
      const m = rule.re.exec(rest);
      if (!m || (best !== undefined && m.index >= best.index)) continue;
      const inner = m[1] ?? '';
      const node: TextNode =
        rule.kind === 'block' || rule.kind === 'mono'
          ? { type: rule.kind, value: inner }
          : { type: rule.kind, children: parseFormatting(inner) };
      best = { index: m.index, length: m[0].length, node };
    }

    const link = URL_RE.exec(rest);
    if (link && (best === undefined || link.index < best.index)) {
      const href = link[0].replace(TRAILING_PUNCTUATION, '');
      best = { index: link.index, length: href.length, node: { type: 'link', href, label: href } };
    }

    if (!best) {
      nodes.push({ type: 'text', value: rest });
      break;
    }
    if (best.index > 0) nodes.push({ type: 'text', value: rest.slice(0, best.index) });
    nodes.push(best.node);
    rest = rest.slice(best.index + best.length);
  }

  return nodes;
}
```

```tsx
import type { ReactNode } from 'react';
import { parseFormatting, type TextNode } from './format-text';

function renderNode(node: TextNode, key: number): ReactNode {
  switch (node.type) {
    case 'text':
      return node.value;
    case 'bold':
      return <strong key={key}>{node.children.map(renderNode)}</strong>;
    case 'italic':
      return <em key={key}>{node.children.map(renderNode)}</em>;
    case 'strike':
      return <del key={key}>{node.children.map(renderNode)}</del>;
    case 'mono':
      return (
        <code key={key} className="mono">
          {node.value}
        </code>
      );
    case 'block':
      return (
        <pre key={key} className="mono mono--block">
          {node.value}
        </pre>
      );
    case 'link':
      return (
        <a key={key} href={node.href} target="_blank" rel="noopener noreferrer">
          {node.label}
        </a>
      );
  }
}

/** Renders server-provided text with WhatsApp formatting. Everything is text; never HTML. */
export function FormattedText({ text }: { text: string }) {
  return <>{parseFormatting(text).map(renderNode)}</>;
```

```ts
import type { ServerEvent } from '@seguradora/protocol';
import type { OutStatus } from '../ui/bubble-types';

export type { OutStatus };

export type BotMessageEvent = Extract<ServerEvent, { type: `message.${string}` }>;

export type UserContent =
  | { type: 'text'; text: string }
  | { type: 'voice'; durationMs: number; objectUrl?: string }
  | { type: 'quick_reply'; optionId: string; title: string }
  | { type: 'flow_submit'; flowId: string; summary: string };

export type UserItem = {
  kind: 'user';
  id: string;
  ts: string;
  status: OutStatus;
  content: UserContent;
};
export type BotItem = { kind: 'bot'; id: string; seq: number; ts: string; event: BotMessageEvent };
export type NoticeItem = { kind: 'notice'; id: string; ts: string; tone: 'info' | 'error'; text: string };
export type ChatItem = UserItem | BotItem | NoticeItem;

export type Connection = 'connecting' | 'online' | 'reconnecting' | 'offline';

export interface ChatState {
  items: ChatItem[];
  typing: boolean;
  connection: Connection;
  /** Highest server `seq` applied in the current session (0 when none). */
  lastSeq: number;
  sessionId?: string;
  /** Ids of bot events already shown (dedupe across replays). */
  seen: Record<string, true>;
}

export const MAX_ITEMS = 500;

export const initialState = (): ChatState => ({
  items: [],
  typing: false,
  connection: 'connecting',
  lastSeq: 0,
  seen: {},
});

export function lastBotItemId(state: ChatState): string | undefined {
  for (let i = state.items.length - 1; i >= 0; i--) {
    const item = state.items[i];
    if (item?.kind === 'bot') return item.id;
  }
  return undefined;
}

/** Quick replies and template buttons are live only on the last bot message, until the user answers. */
export function isInteractive(state: ChatState, itemId: string): boolean {
  if (lastBotItemId(state) !== itemId) return false;
  for (let i = state.items.length - 1; i >= 0; i--) {
    const item = state.items[i];
    if (item?.kind === 'user') return false;
    if (item?.kind === 'bot' && item.id === itemId) return true;
  }
  return false;
}
```

```ts
import type { ServerEvent } from '@seguradora/protocol';
import {
  initialState,
  MAX_ITEMS,
  type BotMessageEvent,
  type ChatItem,
  type ChatState,
  type Connection,
  type OutStatus,
  type UserItem,
} from './model';

export type Action =
  | { type: 'restore'; state: ChatState }
  | { type: 'session'; sessionId: string }
  | { type: 'session_reset'; ts: string }
  | { type: 'user_queued'; item: UserItem }
  | { type: 'user_status'; id: string; status: OutStatus }
  | { type: 'server_event'; event: ServerEvent }
  | { type: 'connection'; connection: Connection };

const RANK: Record<OutStatus, number> = { failed: 0, sending: 1, sent: 2, delivered: 3 };

const cap = (items: ChatItem[]): ChatItem[] =>
  items.length > MAX_ITEMS ? items.slice(items.length - MAX_ITEMS) : items;

const mapUser = (items: ChatItem[], id: string, fn: (u: UserItem) => UserItem): ChatItem[] =>
  items.map((i) => (i.kind === 'user' && i.id === id ? fn(i) : i));

const isMessage = (e: ServerEvent): e is BotMessageEvent => e.type.startsWith('message.');

export function chatReducer(state: ChatState, action: Action): ChatState {
  switch (action.type) {
    case 'restore':
      return { ...action.state, connection: 'connecting', typing: false };

    case 'session':
      return { ...state, sessionId: action.sessionId };

    case 'session_reset':
      return {
        ...state,
        lastSeq: 0,
        typing: false,
        items: cap([
          ...state.items,
          {
            kind: 'notice',
            id: `reset-${action.ts}`,
            ts: action.ts,
            tone: 'info',
            text: 'Uma nova conversa foi iniciada.',
          },
        ]),
      };

    case 'connection':
      return { ...state, connection: action.connection };

    case 'user_queued': {
      if (state.items.some((i) => i.kind === 'user' && i.id === action.item.id)) return state;
      return { ...state, items: cap([...state.items, action.item]) };
    }

    case 'user_status':
      return {
        ...state,
        items: mapUser(state.items, action.id, (u) => {
          // Only a resend (failed → sending) may lower the status; otherwise it only moves forward.
          const resend = u.status === 'failed' && action.status === 'sending';
          return resend || RANK[action.status] > RANK[u.status] ? { ...u, status: action.status } : u;
        }),
      };

    case 'server_event':
      return applyServerEvent(state, action.event);
  }
}

function applyServerEvent(state: ChatState, event: ServerEvent): ChatState {
  if (event.seq <= state.lastSeq) return state;

  let next: ChatState = { ...state, lastSeq: event.seq };
  if (state.lastSeq > 0 && event.seq > state.lastSeq + 1 && !state.items.some((i) => i.id === 'gap-notice')) {
    next = {
      ...next,
      items: cap([
        ...next.items,
        {
          kind: 'notice',
          id: 'gap-notice',
          ts: event.ts,
          tone: 'info',
          text: 'Algumas mensagens podem ter sido perdidas durante a reconexão.',
        },
      ]),
    };
  }

  if (isMessage(event)) {
    if (next.seen[event.id]) return next;
    return {
      ...next,
      typing: false,
      seen: { ...next.seen, [event.id]: true },
      items: cap([...next.items, { kind: 'bot', id: event.id, seq: event.seq, ts: event.ts, event }]),
    };
  }

  switch (event.type) {
    case 'status.typing':
      return { ...next, typing: event.payload.state === 'start' };
    case 'status.delivered':
      return {
        ...next,
        items: mapUser(next.items, event.payload.messageId, (u) => ({ ...u, status: 'delivered' })),
      };
    case 'status.read':
      return next;
    case 'error': {
      const { messageId, message } = event.payload;
      if (messageId) {
        return {
          ...next,
          typing: false,
          items: mapUser(next.items, messageId, (u) => ({ ...u, status: 'failed' })),
        };
      }
      return {
        ...next,
        typing: false,
        items: cap([
          ...next.items,
          { kind: 'notice', id: event.id, ts: event.ts, tone: 'error', text: message },
        ]),
      };
    }
    default:
      return next;
  }
}

export { initialState };
```

```ts
export interface SseMessage {
  id?: string;
  event?: string;
  data: string;
}

export interface SseParserHandlers {
  onMessage(message: SseMessage): void;
  onRetry?(ms: number): void;
  /** Called for comment lines (heartbeats). */
  onActivity?(): void;
}

const MAX_BUFFER = 1_000_000;

/** Incremental `text/event-stream` parser (blank-line dispatch, multi-line data, CRLF tolerant). */
export function createSseParser(handlers: SseParserHandlers) {
  let buffer = '';
  let id: string | undefined;
  let event: string | undefined;
  let data: string[] = [];

  const dispatch = () => {
    if (data.length > 0) {
      handlers.onMessage({
        ...(id !== undefined ? { id } : {}),
        ...(event !== undefined ? { event } : {}),
        data: data.join('\n'),
      });
    }
    id = undefined;
    event = undefined;
    data = [];
  };

  const onLine = (line: string) => {
    if (line === '') return dispatch();
    if (line.startsWith(':')) return handlers.onActivity?.();
    const colon = line.indexOf(':');
    const field = colon === -1 ? line : line.slice(0, colon);
    let value = colon === -1 ? '' : line.slice(colon + 1);
    if (value.startsWith(' ')) value = value.slice(1);
    switch (field) {
      case 'id':
        id = value;
        break;
      case 'event':
        event = value;
        break;
      case 'data':
        data.push(value);
        break;
      case 'retry':
        if (/^\d+$/.test(value)) handlers.onRetry?.(Number(value));
        break;
    }
  };

  return {
    feed(chunk: string): void {
      buffer += chunk;
      if (buffer.length > MAX_BUFFER) {
        buffer = '';
        throw new Error('SSE buffer limit exceeded');
      }
      for (;;) {
        const m = /\r\n|\n|\r/.exec(buffer);
        if (!m) return;
        // A lone \r at the very end may be the first half of \r\n: wait for more data.
        if (m[0] === '\r' && m.index === buffer.length - 1) return;
        const line = buffer.slice(0, m.index);
        buffer = buffer.slice(m.index + m[0].length);
        onLine(line);
      }
    },
  };
}
```

```ts
import { createSseParser, type SseMessage } from './sse-parser';

export type DisconnectReason = 'network' | 'http' | 'timeout' | 'ended';

export interface SseClientOptions {
  url: string;
  fetchImpl?: typeof fetch;
  getLastEventId(): string | undefined;
  onMessage(message: SseMessage): void;
  onOpen?(): void;
  onDisconnect?(reason: DisconnectReason): void;
  onUnauthorized?(): void;
  heartbeatTimeoutMs?: number;
  backoff?: { baseMs: number; maxMs: number };
  random?(): number;
}

const sleep = (ms: number) => new Promise<void>((resolve) => setTimeout(resolve, ms));

/** Fetch-based SSE client: reconnects with jittered exponential backoff and `Last-Event-ID`. */
export class SseClient {
  private running = false;
  private generation = 0;
  private controller: AbortController | undefined;
  private serverRetryMs: number | undefined;

  constructor(private readonly o: SseClientOptions) {}

  start(): void {
    if (this.running) return;
    this.running = true;
    const generation = ++this.generation;
    void this.loop(generation);
  }

  stop(): void {
    this.running = false;
    this.generation++;
    this.controller?.abort();
  }

  private delay(attempt: number): number {
    const { baseMs, maxMs } = this.o.backoff ?? { baseMs: 1000, maxMs: 30000 };
    const random = this.o.random ?? Math.random;
    const exponential = Math.min(maxMs, baseMs * 2 ** attempt);
    const jittered = exponential * (0.5 + random() / 2);
    return Math.max(this.serverRetryMs ?? 0, Math.round(jittered));
  }

  private async loop(generation: number): Promise<void> {
    const alive = () => this.running && this.generation === generation;
    const fetchImpl = this.o.fetchImpl ?? fetch;
    const heartbeatTimeoutMs = this.o.heartbeatTimeoutMs ?? 45000;
    let attempt = 0;

    while (alive()) {
      const controller = new AbortController();
      this.controller = controller;
      let reason: DisconnectReason = 'network';
      let timer: ReturnType<typeof setTimeout> | undefined;
      const arm = () => {
        clearTimeout(timer);
        timer = setTimeout(() => {
          reason = 'timeout';
          controller.abort();
        }, heartbeatTimeoutMs);
      };

      try {
        const last = this.o.getLastEventId();
        const res = await fetchImpl(this.o.url, {
          headers: { accept: 'text/event-stream', ...(last ? { 'last-event-id': last } : {}) },
          credentials: 'include',
          cache: 'no-store',
          signal: controller.signal,
        });

        if (res.status === 401) {
          this.running = false;
          this.o.onUnauthorized?.();
          return;
        }
        if (!res.ok || !res.body) {
          reason = 'http';
        } else {
          attempt = 0;
          this.o.onOpen?.();
          arm();
          const parser = createSseParser({
            onMessage: (m) => this.o.onMessage(m),
            onRetry: (ms) => {
              this.serverRetryMs = ms;
            },
          });
          const reader = res.body.pipeThrough(new TextDecoderStream()).getReader();
          for (;;) {
            const { done, value } = await reader.read();
            if (done) {
              reason = 'ended';
              break;
            }
            arm();
            parser.feed(value);
          }
        }
      } catch {
        // aborted by stop() or by the heartbeat watchdog, or a network failure: `reason` says which
      } finally {
        clearTimeout(timer);
      }

      if (!alive()) return;
      this.o.onDisconnect?.(reason);
      await sleep(this.delay(attempt++));
    }
  }
}
```

```ts
import { parseServerEvent, type ClientEvent, type ServerEvent } from '@seguradora/protocol';
import { SseClient, type SseClientOptions } from './sse-client';
import type { SseMessage } from './sse-parser';

export type Draft =
  | { type: 'user.text'; payload: { text: string } }
  | { type: 'user.voice'; payload: { mediaId: string; durationMs: number } }
  | { type: 'user.quick_reply'; payload: { optionId: string; replyToId: string } }
  | { type: 'user.flow_submit'; payload: { flowId: string; data: Record<string, unknown> } };

export type OutgoingStatus = 'sending' | 'sent' | 'failed';
export type ConnectionState = 'connecting' | 'online' | 'reconnecting' | 'offline';

export interface ChatClientOptions {
  baseUrl?: string;
  fetchImpl?: typeof fetch;
  newId?(): string;
  now?(): number;
  createSse?(o: SseClientOptions): { start(): void; stop(): void };
  onServerEvent(event: ServerEvent): void;
  onConnection(connection: ConnectionState): void;
  onOutgoing(id: string, status: OutgoingStatus): void;
  onSession(sessionId: string, kind: 'new' | 'resumed'): void;
  onSessionReset(): void;
  ackDelayMs?: number;
  maxSendAttempts?: number;
  retryBaseMs?: number;
}

interface OutboxEntry {
  id: string;
  draft: Draft;
  ts: string;
}

type PostResult =
  | { kind: 'ok' }
  | { kind: 'unauthorized' }
  | { kind: 'rate_limited'; retryAfterMs: number }
  | { kind: 'rejected' }
  | { kind: 'retry' };

const OUTBOX_LIMIT = 50;
const sleep = (ms: number) => new Promise<void>((resolve) => setTimeout(resolve, ms));

export class ChatClient {
  private sessionIdValue: string | undefined;
  private lastSeq = 0;
  private ackedSeq = 0;
  private stopped = true;
  private sse: { start(): void; stop(): void } | undefined;
  private ackTimer: ReturnType<typeof setTimeout> | undefined;
  private readonly outbox = new Map<string, OutboxEntry>();
  private resetting: Promise<void> | undefined;
  private generation = 0;

  constructor(private readonly o: ChatClientOptions) {}

  get sessionId(): string | undefined {
    return this.sessionIdValue;
  }

  private get base(): string {
    return this.o.baseUrl ?? '';
  }

  private get fetchImpl(): typeof fetch {
    return this.o.fetchImpl ?? fetch;
  }

  private newId(): string {
    return (this.o.newId ?? (() => crypto.randomUUID()))();
  }

  async start(initial?: { sessionId: string; lastSeq: number }): Promise<void> {
    this.stopped = false;
    const generation = ++this.generation;
    if (initial) {
      this.sessionIdValue = initial.sessionId;
      this.lastSeq = initial.lastSeq;
      this.ackedSeq = initial.lastSeq;
      this.o.onSession(initial.sessionId, 'resumed');
    } else {
      await this.createSession('new');
      if (this.stopped || this.generation !== generation) return;
    }
    this.startStream();
  }

  stop(): void {
    this.stopped = true;
    this.generation++;
    clearTimeout(this.ackTimer);
    this.ackTimer = undefined;
    this.sse?.stop();
    this.sse = undefined;
  }

  send(draft: Draft): string {
    const id = this.newId();
    const entry: OutboxEntry = { id, draft, ts: new Date((this.o.now ?? Date.now)()).toISOString() };
    this.outbox.set(id, entry);
    if (this.outbox.size > OUTBOX_LIMIT) {
      const oldest = this.outbox.keys().next().value;
      if (oldest !== undefined) this.outbox.delete(oldest);
    }
    this.o.onOutgoing(id, 'sending');
    void this.deliver(entry);
    return id;
  }

  resend(id: string): void {
    const entry = this.outbox.get(id);
    if (!entry) return;
    this.o.onOutgoing(id, 'sending');
    void this.deliver(entry);
  }

  // ---- session ---------------------------------------------------------------------------

  private async createSession(kind: 'new'): Promise<void> {
    this.o.onConnection('connecting');
    for (let attempt = 0; !this.stopped; attempt++) {
      try {
        const res = await this.fetchImpl(`${this.base}/v1/session`, {
          method: 'POST',
          credentials: 'include',
        });
        if (res.status === 201) {
          const body = (await res.json()) as { sessionId?: unknown };
          if (typeof body.sessionId === 'string') {
            this.sessionIdValue = body.sessionId;
            this.lastSeq = 0;
            this.ackedSeq = 0;
            this.o.onSession(body.sessionId, kind);
            return;
          }
        }
      } catch {
        // network failure: retry below
      }
      this.o.onConnection('offline');
      await sleep(Math.min(30000, (this.o.retryBaseMs ?? 500) * 2 ** attempt));
    }
  }

  private resetSession(): Promise<void> {
    if (this.resetting) return this.resetting;
    this.sse?.stop();
    this.resetting = (async () => {
      try {
        await this.createSession('new');
        if (this.stopped) return;
        this.o.onSessionReset();
        this.startStream();
      } finally {
        this.resetting = undefined;
      }
    })();
    return this.resetting;
  }

  // ---- stream ----------------------------------------------------------------------------

  private startStream(): void {
    this.sse?.stop();
    const options: SseClientOptions = {
      url: `${this.base}/v1/stream`,
      ...(this.o.fetchImpl ? { fetchImpl: this.o.fetchImpl } : {}),
      getLastEventId: () => (this.lastSeq > 0 ? String(this.lastSeq) : undefined),
      onMessage: (m) => this.handleMessage(m),
      onOpen: () => this.o.onConnection('online'),
      onDisconnect: () => this.o.onConnection('reconnecting'),
      onUnauthorized: () => void this.resetSession(),
    };
    this.sse = (this.o.createSse ?? ((opts) => new SseClient(opts)))(options);
    this.sse.start();
  }

  private handleMessage(message: SseMessage): void {
    let json: unknown;
    try {
      json = JSON.parse(message.data);
    } catch {
      return;
    }
    const parsed = parseServerEvent(json);
    if (!parsed.ok) return;
    const event = parsed.value;
    if (event.seq > this.lastSeq) this.lastSeq = event.seq;
    this.o.onServerEvent(event);
    this.scheduleAck();
  }

  private scheduleAck(): void {
    if (this.ackTimer || this.stopped) return;
    this.ackTimer = setTimeout(() => {
      this.ackTimer = undefined;
      if (this.stopped || this.lastSeq <= this.ackedSeq || !this.sessionIdValue) return;
      const lastSeq = this.lastSeq;
      this.ackedSeq = lastSeq;
      // Best effort: an ack that fails is simply superseded by the next one.
      void this.post(this.envelope(this.newId(), new Date((this.o.now ?? Date.now)()).toISOString(), {
        type: 'user.ack',
        payload: { lastSeq },
      })).catch(() => undefined);
    }, this.o.ackDelayMs ?? 300);
  }

  // ---- sending ---------------------------------------------------------------------------

  private envelope(
    id: string,
    ts: string,
    draft: Draft | { type: 'user.ack'; payload: { lastSeq: number } },
  ): ClientEvent {
    return {
      v: 1,
      id,
      sessionId: this.sessionIdValue ?? '',
      correlationId: `web-${id}`,
      ts,
      ...draft,
    } as ClientEvent;
  }

  private async post(event: ClientEvent): Promise<PostResult> {
    let res: Response;
    try {
      res = await this.fetchImpl(`${this.base}/v1/events`, {
        method: 'POST',
        credentials: 'include',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify(event),
      });
    } catch {
      return { kind: 'retry' };
    }
    if (res.status === 202 || res.status === 200) return { kind: 'ok' };
    if (res.status === 401) return { kind: 'unauthorized' };
    if (res.status === 429) {
      const seconds = Number(res.headers.get('retry-after'));
      return { kind: 'rate_limited', retryAfterMs: Number.isFinite(seconds) && seconds > 0 ? seconds * 1000 : 1000 };
    }
    if (res.status >= 500) return { kind: 'retry' };
    return { kind: 'rejected' };
  }

  private async deliver(entry: OutboxEntry): Promise<void> {
    const maxAttempts = this.o.maxSendAttempts ?? 4;
    const retryBase = this.o.retryBaseMs ?? 500;
    let attempts = 0;

    while (!this.stopped) {
      if (this.resetting) await this.resetting;
      if (this.stopped) return;
      attempts++;
      const result = await this.post(this.envelope(entry.id, entry.ts, entry.draft));

      switch (result.kind) {
        case 'ok':
          this.o.onOutgoing(entry.id, 'sent');
          return;
        case 'rejected':
          this.o.onOutgoing(entry.id, 'failed');
          return;
        case 'unauthorized':
          await this.resetSession();
          attempts--; // a session change is not the message's fault
          continue;
        case 'rate_limited':
          if (attempts >= maxAttempts) break;
          await sleep(result.retryAfterMs);
          continue;
        case 'retry':
          if (attempts >= maxAttempts) break;
          await sleep(retryBase * 2 ** (attempts - 1));
          continue;
      }
      this.o.onOutgoing(entry.id, 'failed');
      return;
    }
  }
}
```

```ts
function fakeLocks() {
  const holders = new Map<string, { release(): void; abort(): void }>();
  const manager = {
    request(name: string, options: { ifAvailable?: boolean; steal?: boolean }, cb: (lock: object | null) => Promise<void>) {
      const current = holders.get(name);
      if (current && options.ifAvailable) return cb(null).then(() => undefined);
      if (current && options.steal) current.abort();
      return new Promise<void>((resolve, reject) => {
        let released = false;
        const entry = {
          release: () => {
            if (!released) {
              released = true;
              holders.delete(name);
              resolve();
            }
          },
          abort: () => {
            released = true;
            holders.delete(name);
            reject(new DOMException('stolen', 'AbortError'));
```

```ts
import { MAX_ITEMS, initialState, type ChatItem, type ChatState } from './model';

const KEY = 'seguradora-chat:v1';
const KEEP = 200;

interface Stored {
  v: 1;
  sessionId: string;
  lastSeq: number;
  items: ChatItem[];
}

/** Makes an item safe to store: no blob URLs (they die with the page) and no in-flight statuses. */
function toStorable(item: ChatItem): ChatItem {
  if (item.kind !== 'user') return item;
  const status = item.status === 'sending' ? 'failed' : item.status;
  if (item.content.type === 'voice') {
    const { objectUrl: _objectUrl, ...voice } = item.content;
    return { ...item, status, content: voice };
  }
  return { ...item, status };
}

export function saveChat(storage: Storage, state: ChatState): void {
  if (!state.sessionId) return;
  const stored: Stored = {
    v: 1,
    sessionId: state.sessionId,
    lastSeq: state.lastSeq,
    items: state.items.slice(-KEEP).map(toStorable),
  };
  try {
    storage.setItem(KEY, JSON.stringify(stored));
  } catch {
    // storage full or unavailable: the chat keeps working without persistence
  }
}

export function loadChat(storage: Storage): ChatState | undefined {
  let raw: string | null;
  try {
    raw = storage.getItem(KEY);
  } catch {
    return undefined;
  }
  if (!raw) return undefined;
  let data: unknown;
  try {
    data = JSON.parse(raw);
  } catch {
    return undefined;
  }
  if (typeof data !== 'object' || data === null) return undefined;
  const s = data as Partial<Stored>;
  if (s.v !== 1 || typeof s.sessionId !== 'string' || typeof s.lastSeq !== 'number' || !Array.isArray(s.items)) {
    return undefined;
  }
  const items = s.items.slice(-MAX_ITEMS) as ChatItem[];
  const seen: Record<string, true> = {};
  for (const item of items) if (item.kind === 'bot') seen[item.id] = true;
  return { ...initialState(), sessionId: s.sessionId, lastSeq: s.lastSeq, items, seen };
}
```

```ts
export type TabStatus = 'active' | 'other-tab';

export interface TabGuard {
  status(): TabStatus;
  subscribe(fn: (status: TabStatus) => void): () => void;
  takeOver(): void;
  dispose(): void;
}

/**
 * Only one tab may hold the chat stream (the gateway keeps one stream per session). The tab
 * that holds the Web Lock is `active`; the others show a notice and may take over.
 */
export function createTabGuard(locks: LockManager | undefined, name = 'seguradora-chat'): TabGuard {
  const listeners = new Set<(s: TabStatus) => void>();
  let current: TabStatus = locks ? 'other-tab' : 'active';
  let release: (() => void) | undefined;
  let disposed = false;

  const set = (next: TabStatus) => {
    if (current === next) return;
    current = next;
    for (const fn of listeners) fn(next);
  };

  const request = (steal: boolean) => {
    if (!locks || disposed) return;
    const options = steal ? { steal: true } : { ifAvailable: true };
    locks
      .request(name, options, async (lock) => {
        if (!lock) {
          set('other-tab');
          return;
        }
        if (disposed) return;
        set('active');
        // Hold the lock until this tab is disposed (or the lock is stolen, which rejects below).
        await new Promise<void>((resolve) => {
          release = resolve;
        });
      })
      .catch(() => {
        // Stolen by another tab: this one is demoted and does not fight back.
        set('other-tab');
      });
  };

  request(false);

  return {
    status: () => current,
    subscribe(fn) {
      listeners.add(fn);
      return () => {
        listeners.delete(fn);
      };
    },
    takeOver: () => request(true),
    dispose() {
      disposed = true;
      release?.();
      listeners.clear();
    },
  };
}
```

```ts
import { useEffect, useMemo, useState } from 'react';
import { createTabGuard, type TabGuard, type TabStatus } from './tab-lock';

export function useTabGuard(external?: TabGuard): { status: TabStatus; takeOver(): void } {
  const guard = useMemo(
    () => external ?? createTabGuard(typeof navigator === 'undefined' ? undefined : navigator.locks),
    [external],
  );
  const [status, setStatus] = useState<TabStatus>(guard.status());

  useEffect(() => {
    setStatus(guard.status());
    const off = guard.subscribe(setStatus);
    return () => {
      off();
      if (!external) guard.dispose();
    };
  }, [guard, external]);

  return { status, takeOver: () => guard.takeOver() };
}
```

```ts
import { useCallback, useEffect, useReducer, useRef } from 'react';
import { ChatClient, type ChatClientOptions, type Draft } from '../transport/chat-client';
import { initialState, type ChatState, type UserContent, type UserItem } from './model';
import { loadChat, saveChat } from './persistence';
import { chatReducer } from './reducer';
import type { TabGuard, TabStatus } from './tab-lock';
import { useTabGuard } from './useTabGuard';

export interface ChatClientLike {
  start(initial?: { sessionId: string; lastSeq: number }): Promise<void>;
  stop(): void;
  send(draft: Draft): string;
  resend(id: string): void;
}

export interface UseChatOptions {
  createClient?(o: ChatClientOptions): ChatClientLike;
  storage?: Storage;
  guard?: TabGuard;
  now?(): number;
}

export interface ChatApi {
  state: ChatState;
  tab: TabStatus;
  sendText(text: string): void;
  sendChoice(optionId: string, title: string, replyToId: string): void;
  sendVoice(blob: Blob, durationMs: number): void;
  sendFlowSubmit(flowId: string, data: Record<string, unknown>, summary: string): void;
  resend(id: string): void;
  takeOver(): void;
}

const SAVE_DELAY_MS = 300;

export function useChat(options: UseChatOptions = {}): ChatApi {
  const storage = options.storage ?? (typeof sessionStorage === 'undefined' ? undefined : sessionStorage);
  const now = options.now ?? Date.now;
  const [state, dispatch] = useReducer(chatReducer, undefined, () => (storage && loadChat(storage)) || initialState());
  const guard = useTabGuard(options.guard);
  const clientRef = useRef<ChatClientLike | undefined>(undefined);
  const stateRef = useRef(state);
  stateRef.current = state;

  // (Re)start the client while this tab owns the chat.
  useEffect(() => {
    if (guard.status !== 'active') return;
    const create = options.createClient ?? ((o: ChatClientOptions) => new ChatClient(o));
    const client = create({
      onServerEvent: (event) => dispatch({ type: 'server_event', event }),
      onConnection: (connection) => dispatch({ type: 'connection', connection }),
      onOutgoing: (id, status) => dispatch({ type: 'user_status', id, status }),
      onSession: (sessionId) => dispatch({ type: 'session', sessionId }),
      onSessionReset: () => dispatch({ type: 'session_reset', ts: new Date(now()).toISOString() }),
    });
    clientRef.current = client;
    const saved = stateRef.current;
    void client.start(saved.sessionId ? { sessionId: saved.sessionId, lastSeq: saved.lastSeq } : undefined);
    return () => {
      client.stop();
      clientRef.current = undefined;
    };
    // The client is created once per ownership change; options are read at that moment.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [guard.status]);

  // Persist the conversation (debounced).
  useEffect(() => {
    if (!storage) return;
    const timer = setTimeout(() => saveChat(storage, state), SAVE_DELAY_MS);
    return () => clearTimeout(timer);
  }, [state, storage]);

  const queue = useCallback(
    (draft: Draft, content: UserContent) => {
      const client = clientRef.current;
      if (!client) return;
      const id = client.send(draft);
      const item: UserItem = { kind: 'user', id, ts: new Date(now()).toISOString(), status: 'sending', content };
      dispatch({ type: 'user_queued', item });
    },
    [now],
  );

  return {
    state,
    tab: guard.status,
    sendText: (text) => {
      const trimmed = text.trim();
      if (!trimmed) return;
      queue({ type: 'user.text', payload: { text: trimmed } }, { type: 'text', text: trimmed });
    },
    sendChoice: (optionId, title, replyToId) =>
      queue({ type: 'user.quick_reply', payload: { optionId, replyToId } }, { type: 'quick_reply', optionId, title }),
    sendVoice: (blob, durationMs) => {
      const objectUrl = URL.createObjectURL(blob);
      queue(
        { type: 'user.voice', payload: { mediaId: `local-${crypto.randomUUID()}`, durationMs } },
        { type: 'voice', durationMs, objectUrl },
      );
    },
    sendFlowSubmit: (flowId, data, summary) =>
      queue({ type: 'user.flow_submit', payload: { flowId, data } }, { type: 'flow_submit', flowId, summary }),
    resend: (id) => {
      clientRef.current?.resend(id);
    },
    takeOver: guard.takeOver,
  };
}
```

```tsx
export function CodeMessage({ code, language }: { code: string; language?: string }) {
  const [copied, setCopied] = useState(false);

    try {

      <div className="code__bar">
        {language ? <span className="code__lang">{language}</span> : <span />}
        <button type="button" className="code__copy" onClick={copy}>
          <CopyIcon /> {copied ? 'Copiado' : 'Copiar'}
        </button>
      </div>
      <pre className="code__body">
        <code>{code}</code>
      </pre>
    </div>
  );
}
```

```ts
/** http(s) only: blocks javascript:, data:, vbscript: and malformed values. Never throws. */
export function safeHttpUrl(value: string): string | undefined {
  try {
    const url = new URL(value);
    return url.protocol === 'http:' || url.protocol === 'https:' ? url.href : undefined;
  } catch {
    return undefined;
  }
}

/** A `tel:` href built only from digits, +, spaces, parentheses and hyphens (spaces removed). */
export function safeTelHref(phone: string): string | undefined {
  return /^[\d+()\-\s]{3,30}$/.test(phone) ? `tel:${phone.replace(/\s+/g, '')}` : undefined;
}

/** Blob URLs created by this page for the user's own recordings. */
export function safeMediaUrl(value: string): string | undefined {
  if (value.startsWith('blob:')) return value;
  return safeHttpUrl(value);
}
```

```tsx
const BARS = 28;

function waveform(id: string): number[] {
  let seed = 0;
  for (const ch of id) seed = (seed * 31 + ch.charCodeAt(0)) >>> 0;
  return Array.from({ length: BARS }, () => {
    seed = (seed * 1664525 + 1013904223) >>> 0;
    return 20 + (seed % 80);
  });
}

const formatDuration = (ms: number): string => {
  const total = Math.max(0, Math.round(ms / 1000));
  return `${Math.floor(total / 60)}:${String(total % 60).padStart(2, '0')}`;
};

export interface VoiceMessageProps {
  id: string;
  mediaUrl: string;
  durationMs: number;
  transcript?: string | undefined;
}

export function VoiceMessage({ id, mediaUrl, durationMs, transcript }: VoiceMessageProps) {
  const src = safeMediaUrl(mediaUrl);
  const audio = useRef<HTMLAudioElement>(null);
  const [playing, setPlaying] = useState(false);
  const [broken, setBroken] = useState(false);
  const unavailable = !src || broken;

  const toggle = () => {
    const el = audio.current;
    if (!el) return;
    if (playing) {
      el.pause();
      setPlaying(false);
    } else {
      void el.play();
      setPlaying(true);
    }
  };

  return (
    <div className="voice">
      <button
        type="button"
        className="voice__button"
        aria-label={playing ? 'Pausar áudio' : 'Reproduzir áudio'}
        disabled={unavailable}
        onClick={toggle}
      >
        {playing ? <PauseIcon /> : <PlayIcon />}
      </button>
      <div className="voice__wave" aria-hidden="true">
        {waveform(id).map((h, i) => (
          <span key={i} style={{ height: `${h}%` }} />
        ))}
      </div>
      <span className="voice__duration">{formatDuration(durationMs)}</span>
      {unavailable ? <span className="voice__error">Áudio indisponível</span> : null}
      {src ? (
        <audio
          ref={audio}
          src={src}
          preload="none"
          onEnded={() => setPlaying(false)}
          onError={() => setBroken(true)}
        />
      ) : null}
      {transcript ? <p className="voice__transcript">{transcript}</p> : null}
    </div>
  );
}
```

```tsx
import type { ReactNode } from 'react';
import type { BotItem } from '../chat/model';
import { Bubble } from '../ui/Bubble';
import { formatTime } from '../ui/time';
import { CarouselMessage } from './CarouselMessage';
import { CodeMessage } from './CodeMessage';
import type { OpenFlow } from './flow-host';
import { FlowMessage } from './FlowMessage';
import { LocationMessage } from './LocationMessage';
import { QuickReplies } from './QuickReplies';
import { TemplateMessage } from './TemplateMessage';
import { FormattedText } from './TextMessage';
import { VoiceMessage } from './VoiceMessage';

export interface RenderContext {
  /** True while this is the last bot message and the user has not answered yet. */
  interactive: boolean;
  sendChoice(optionId: string, title: string, replyToId: string): void;
  openFlow: OpenFlow;
}

/** Maps one server message event to its component (exhaustive over `message.*`). */
export function renderBotMessage(item: BotItem, ctx: RenderContext): ReactNode {
  const event = item.event;
  const time = formatTime(item.ts);
  const onChoice = (optionId: string, title: string) => ctx.sendChoice(optionId, title, item.id);
  const bubble = (content: ReactNode, label = 'Mensagem do assistente') => (
    <Bubble key={item.id} direction="in" time={time} label={label}>
      {content}
    </Bubble>
  );

  switch (event.type) {
    case 'message.text':
      return bubble(<FormattedText text={event.payload.text} />);
    case 'message.code':
      return bubble(<CodeMessage code={event.payload.code} {...(event.payload.language ? { language: event.payload.language } : {})} />);
    case 'message.location':
      return bubble(
        <LocationMessage
          latitude={event.payload.latitude}
          longitude={event.payload.longitude}
          name={event.payload.name}
          address={event.payload.address}
        />,
        'Localização enviada pelo assistente',
      );
    case 'message.voice':
      return bubble(
        <VoiceMessage
          id={item.id}
          mediaUrl={event.payload.mediaUrl}
          durationMs={event.payload.durationMs}
          transcript={event.payload.transcript}
        />,
        'Mensagem de voz do assistente',
      );
    case 'message.template':
      return bubble(<TemplateMessage payload={event.payload} interactive={ctx.interactive} onChoice={onChoice} />);
    case 'message.quick_replies':
      return bubble(
        <QuickReplies
          text={event.payload.text}
          options={event.payload.options}
          interactive={ctx.interactive}
          onChoice={onChoice}
        />,
      );
    case 'message.carousel':
      return (
        <div key={item.id} className="carousel-row">
          <CarouselMessage cards={event.payload.cards} />
        </div>
      );
    case 'message.flow':
      return bubble(<FlowMessage payload={event.payload} onOpen={ctx.openFlow} />, 'Formulário do assistente');
  }
}
```

```ts
import { useCallback, useEffect, useRef, useState } from 'react';

export type RecorderStatus = 'idle' | 'recording' | 'error';
export interface Recording {
  blob: Blob;
  durationMs: number;
}
export interface VoiceRecorder {
  status: RecorderStatus;
  elapsedMs: number;
  start(): Promise<void>;
  stop(): Promise<Recording | undefined>;
  cancel(): void;
}

export function useVoiceRecorder(options: { maxMs?: number } = {}): VoiceRecorder {
  const maxMs = options.maxMs ?? 120_000;
  const [status, setStatus] = useState<RecorderStatus>('idle');
  const [elapsedMs, setElapsedMs] = useState(0);
  const recorder = useRef<MediaRecorder | undefined>(undefined);
  const stream = useRef<MediaStream | undefined>(undefined);
  const chunks = useRef<Blob[]>([]);
  const startedAt = useRef(0);
  const ticker = useRef<ReturnType<typeof setInterval> | undefined>(undefined);
  const resolveStop = useRef<((r: Recording | undefined) => void) | undefined>(undefined);
  const discard = useRef(false);

  const release = useCallback(() => {
    clearInterval(ticker.current);
    ticker.current = undefined;
    stream.current?.getTracks().forEach((t) => t.stop());
    stream.current = undefined;
    recorder.current = undefined;
  }, []);

  const finish = useCallback(() => {
    const durationMs = Date.now() - startedAt.current;
    const blob = new Blob(chunks.current, { type: chunks.current[0]?.type || 'audio/webm' });
    release();
    setStatus('idle');
    setElapsedMs(0);
    const resolve = resolveStop.current;
    resolveStop.current = undefined;
    resolve?.(discard.current || blob.size === 0 ? undefined : { blob, durationMs });
  }, [release]);

  const start = useCallback(async () => {
    if (typeof MediaRecorder === 'undefined' || !navigator.mediaDevices?.getUserMedia) {
      setStatus('error');
      return;
    }
    try {
      const media = await navigator.mediaDevices.getUserMedia({ audio: true });
      stream.current = media;
      chunks.current = [];
      discard.current = false;
      const rec = new MediaRecorder(media);
      recorder.current = rec;
      rec.ondataavailable = (e) => {
        if (e.data.size > 0) chunks.current.push(e.data);
      };
      rec.onstop = finish;
      startedAt.current = Date.now();
      rec.start();
      setStatus('recording');
      setElapsedMs(0);
      ticker.current = setInterval(() => {
        const elapsed = Date.now() - startedAt.current;
        setElapsedMs(elapsed);
        if (elapsed >= maxMs) rec.stop();
      }, 250);
    } catch {
      release();
      setStatus('error');
    }
  }, [finish, maxMs, release]);

  const stop = useCallback(
    () =>
      new Promise<Recording | undefined>((resolve) => {
        const rec = recorder.current;
        if (!rec || rec.state !== 'recording') return resolve(undefined);
        resolveStop.current = resolve;
        rec.stop();
      }),
    [],
  );

  const cancel = useCallback(() => {
    discard.current = true;
    const rec = recorder.current;
    if (rec && rec.state === 'recording') rec.stop();
    else release();
    setStatus('idle');
    setElapsedMs(0);
  }, [release]);

  useEffect(() => () => release(), [release]);

  return { status, elapsedMs, start, stop, cancel };
}
```

```tsx
  onSendText(text: string): void;
  onSendVoice(blob: Blob, durationMs: number): void;

  disabled?: boolean;

const formatElapsed = (ms: number): string => {
  const total = Math.floor(ms / 1000);
  return `${Math.floor(total / 60)}:${String(total % 60).padStart(2, '0')}`;
};

export function Composer({ onSendText, onSendVoice, recorder, disabled = false }: ComposerProps) {
  const [text, setText] = useState('');
  const input = useRef<HTMLTextAreaElement>(null);

  const send = () => {
    const trimmed = text.trim();
    if (!trimmed) return;
    onSendText(trimmed);
    setText('');
    input.current?.focus();
  };

  const onKeyDown = (e: KeyboardEvent<HTMLTextAreaElement>) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      send();
    }
  };

  const sendRecording = async () => {
    const recording = await recorder.stop();
    if (recording) onSendVoice(recording.blob, recording.durationMs);
  };

  if (recorder.status === 'recording') {
    return (
      <form className="composer composer--recording" onSubmit={(e) => e.preventDefault()}>
        <button type="button" className="composer__icon" aria-label="Cancelar gravação" onClick={recorder.cancel}>
          <CloseIcon />
        </button>
        <span className="composer__timer" role="timer">
          {formatElapsed(recorder.elapsedMs)}
        </span>
        <button type="button" className="composer__action" aria-label="Enviar áudio" onClick={() => void sendRecording()}>
          <StopIcon />
        </button>
      </form>
    );

        maxLength={LIMITS.maxTextLength}
        value={text}

      />
```

```js
import { createServer } from 'node:http';

const PORT = Number(process.env.MOCK_GATEWAY_PORT ?? 8099);
const sessions = new Map(); // sid -> { seq, buffer: [], stream: res | null, valid: true, seen: Set }

const uuid = () => crypto.randomUUID();
const now = () => new Date().toISOString();

function readBody(req) {
  return new Promise((resolve) => {
    const chunks = [];
    req.on('data', (c) => chunks.push(c));
    req.on('end', () => {
      try {
        resolve(JSON.parse(Buffer.concat(chunks).toString('utf8')));
      } catch {
        resolve(undefined);
      }
    });
  });
}

function cookieSid(req) {
  const raw = req.headers.cookie ?? '';
  const m = /(?:^|; )sid=([^;]+)/.exec(raw);
  return m?.[1];
}

function json(res, status, body, headers = {}) {
  res.writeHead(status, { 'content-type': 'application/json', ...headers });
  res.end(JSON.stringify(body));
}

function publish(session, body) {
  session.seq += 1;
  const event = { v: 1, id: uuid(), seq: session.seq, sessionId: session.id, correlationId: 'mock', ts: now(), ...body };
  session.buffer.push(event);
  if (session.buffer.length > 200) session.buffer.shift();
  if (session.stream) {
    session.stream.write(`id: ${event.seq}\nevent: ${event.type}\ndata: ${JSON.stringify(event)}\n\n`);
  }
  return event;
}

const text = (t) => ({ type: 'message.text', payload: { text: t } });

function reply(session, event) {
  const said = event.type === 'user.text' ? event.payload.text.toLowerCase().trim() : '';
  publish(session, { type: 'status.typing', payload: { state: 'start' } });
  setTimeout(() => {
    publish(session, { type: 'status.typing', payload: { state: 'stop' } });
    if (event.type === 'user.quick_reply') {
      if (event.payload.optionId === 'menu.quote') {
        publish(session, {
          type: 'message.flow',
          payload: { flowId: 'cotacao', body: 'Vamos fazer sua cotação.', ctaLabel: 'Começar', flowJson: { screens: [] } },
        });
      } else {
        publish(session, text(`Você escolheu ${event.payload.optionId}.`));
      }
      return;
    }
    if (said === 'oi') {
      publish(session, text('Olá! Eu sou o *assistente* virtual da Seguradora.'));
      publish(session, {
        type: 'message.quick_replies',
        payload: {
          text: 'Escolha uma opção:',
          options: [
            { id: 'menu.quote', title: 'Fazer cotação' },
            { id: 'menu.policies', title: 'Minhas apólices' },
          ],
        },
      });
    } else if (said === 'template') {
      publish(session, {
        type: 'message.template',
        payload: {
          header: 'Apólice AP-1001',
          body: 'Produto: Auto\nSituação: Ativa',
          footer: 'Valores sujeitos a análise.',
          buttons: [
            { type: 'quick_reply', id: 'policy.second_copy:AP-1001', title: 'Segunda via' },
            { type: 'url', title: 'Abrir documento', url: 'https://exemplo.invalid/docs/AP-1001.pdf' },
          ],
        },
      });
    } else if (said === 'carrossel') {
      publish(session, {
        type: 'message.carousel',
        payload: {
          cards: ['Colisão', 'Roubo e furto', 'Incêndio'].map((title) => ({
            mediaUrl: `https://exemplo.invalid/${encodeURIComponent(title)}.png`,
            mediaType: 'image',
            title,
            body: 'Limite: R$ 50.000,00',
            buttons: [],
          })),
        },
      });
    } else if (said === 'codigo') {
      publish(session, { type: 'message.code', payload: { code: 'Protocolo: SN-2002' } });
    } else if (said === 'local') {
      publish(session, {
        type: 'message.location',
        payload: { latitude: -23.5614, longitude: -46.6559, name: 'Agência Paulista', address: 'Av. Paulista, 1000' },
      });
    } else if (said === 'audio') {
      publish(session, { type: 'message.voice', payload: { mediaUrl: 'https://exemplo.invalid/a.ogg', durationMs: 4000 } });
    } else if (said === 'fluxo') {
      publish(session, {
        type: 'message.flow',
        payload: { flowId: 'cotacao', body: 'Preencha o formulário.', ctaLabel: 'Começar', flowJson: { screens: [] } },
      });
    } else if (said === 'erro') {
      publish(session, {
        type: 'error',
        payload: { code: 'upstream_unavailable', message: 'O atendimento está indisponível no momento.', messageId: event.id },
      });
      session.failedOnce.add(event.id);
    } else if (said === 'queda') {
      publish(session, text('Vou derrubar a conexão.'));
      session.stream?.end();
      session.stream = null;
    } else if (said === 'sessao') {
      session.valid = false;
      publish(session, text('Sessão invalidada.'));
    } else {
      publish(session, text(`Você disse: ${event.type === 'user.text' ? event.payload.text : event.type}`));
    }
  }, 40);
}

const server = createServer(async (req, res) => {
  const url = new URL(req.url ?? '/', 'http://mock');

  if (req.method === 'POST' && url.pathname === '/v1/session') {
    const id = uuid();
    sessions.set(id, { id, seq: 0, buffer: [], stream: null, valid: true, seen: new Set(), failedOnce: new Set() });
    return json(res, 201, { sessionId: id }, { 'set-cookie': `sid=${id}; HttpOnly; Path=/; SameSite=Lax` });
  }

  const session = sessions.get(cookieSid(req) ?? '');
  const authorized = session?.valid === true;

  if (req.method === 'GET' && url.pathname === '/v1/stream') {
    if (!authorized || !session) return json(res, 401, { error: { code: 'unauthorized', message: 'Sessão inválida.' } });
    session.stream?.end();
    res.writeHead(200, { 'content-type': 'text/event-stream', 'cache-control': 'no-cache' });
    res.write('retry: 500\n\n');
    session.stream = res;
    const last = Number(req.headers['last-event-id'] ?? 0) || 0;
    for (const e of session.buffer.filter((x) => x.seq > last)) {
      res.write(`id: ${e.seq}\nevent: ${e.type}\ndata: ${JSON.stringify(e)}\n\n`);
    }
    const heartbeat = setInterval(() => res.write(': hb\n\n'), 5000);
    req.on('close', () => {
      clearInterval(heartbeat);
      if (session.stream === res) session.stream = null;
    });
    return undefined;
  }

  if (req.method === 'POST' && url.pathname === '/v1/events') {
    if (!authorized || !session) return json(res, 401, { error: { code: 'unauthorized', message: 'Sessão inválida.' } });
    const event = await readBody(req);
    if (!event || typeof event.id !== 'string' || typeof event.type !== 'string') {
      return json(res, 400, { error: { code: 'invalid_schema', message: 'Evento inválido.' } });
    }
    // Test hook: every accepted event is recorded so the tests can assert ids and order.
    session.posted = session.posted ?? [];
    session.posted.push(event);
    if (event.type === 'user.ack') return json(res, 202, { status: 'accepted' });
    if (session.seen.has(event.id) && !session.failedOnce.has(event.id)) {
      return json(res, 200, { status: 'duplicate' });
    }
    session.failedOnce.delete(event.id);
    session.seen.add(event.id);
    json(res, 202, { status: 'accepted' });
    publish(session, { type: 'status.delivered', payload: { messageId: event.id } });
    reply(session, event);
    return undefined;
  }

  // Test hooks (not part of the gateway contract)
  if (req.method === 'GET' && url.pathname === '/__posted') {
    return json(res, 200, { posted: (session?.posted ?? []).filter((e) => e.type !== 'user.ack') });
  }
  if (req.method === 'POST' && url.pathname === '/__drop-stream') {
    session?.stream?.end();
    if (session) session.stream = null;
    return json(res, 200, { ok: true });
  }
  if (req.method === 'POST' && url.pathname === '/__push') {
    const body = await readBody(req);
    if (session && body) publish(session, body);
    return json(res, 200, { ok: true });
  }

  return json(res, 404, { error: { code: 'invalid_schema', message: 'Rota não encontrada.' } });
});

server.listen(PORT, '127.0.0.1', () => {
  console.log(`mock gateway listening on ${PORT}`);
});
```
