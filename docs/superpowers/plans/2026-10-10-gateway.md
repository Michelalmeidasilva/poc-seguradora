# Gateway: Plano de Implementação (Plano 2 de 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar `apps/gateway`: o serviço público que mantém a sessão anônima, expõe o SSE (`GET /v1/stream`) e recebe eventos (`POST /v1/events`), garante ordenação, idempotência e reenvio, aplica rate limit e repassa cada evento ao chatbot por HTTP + NDJSON com resiliência.

**Architecture:** Hexagonal (`domain` / `application` / `infra` / `main.ts`) em Fastify 5. O domínio guarda, por sessão, um buffer de eventos com `seq`, um cache de idempotência e o pub/sub em memória. O caso de uso `HandleClientEvent` valida limites, repassa ao `ChatbotPort` e publica as respostas na sessão. A infraestrutura traz o JWT (jose), o registro de sessões em memória, o cliente HTTP do chatbot (com `createPolicy`) e as rotas Fastify.

**Tech Stack:** Node 22, TypeScript estrito, Fastify 5 (`@fastify/cookie`, `@fastify/cors`), `jose`, `pino`, Zod 3, Vitest, `tsup` (build), `dependency-cruiser`.

**Spec:** `docs/superpowers/specs/2026-10-10-whatsapp-chatbot-poc-design.md` (seções 3, 6, 9, 10, 14). Código existente que este plano consome: `@seguradora/protocol` (schemas, `parseClientEvent`, `Result`, `LIMITS`, `ERROR_CODES`) e `@seguradora/resilience` (`createPolicy`, `CircuitBreaker`, `Bulkhead`, `TimeoutError`, `CircuitOpenError`, `BulkheadFullError`), ambos já na `master`.

**Execução:** em uma branch nova `feat/gateway`, de preferência em um `git worktree` próprio, partindo da `master`.

## Contrato com o chatbot (consumido pelo Plano 3)

- Gateway → chatbot: `POST {CHATBOT_URL}/v1/chat/events`, `content-type: application/json`, cabeçalho `x-correlation-id`, corpo `ChatbotRequest` `{ v: 1, sessionId, correlationId, event: ClientEvent }`.
- Resposta: `200` com `content-type: application/x-ndjson`; cada linha é um evento do servidor **sem `seq`** (`UnsequencedServerEvent`) com `id` (UUID), `sessionId` igual ao da requisição, `correlationId`, `ts`, `type` e `payload`. A conexão fecha ao fim do turno. A Tarefa 1 adiciona esses schemas ao pacote `protocol`.
- Qualquer status ≠ 2xx é falha. 502/503/504 são repetidos pelo gateway; 4xx não. O chatbot deve ser idempotente pelo `event.id` (o gateway pode repetir a chamada).

## Global Constraints

- Um único repositório git na raiz. Nunca `git init` dentro de `apps/*` ou `packages/*`.
- TypeScript `strict`; Node ≥ 20 (produção em Node 22); pnpm monorepo; validação nas bordas com Zod 3; erros esperados como `Result`.
- Arquitetura hexagonal: dependências só em `infra → application → domain`; o domínio não importa Fastify, pino, jose nem I/O. Injeção de dependência manual no composition root (`compose.ts` e `main.ts`).
- Envelope: `{ v: 1, id, seq, sessionId, correlationId, ts, type, payload }`; `seq` só servidor→cliente, monotônico por sessão, começando em 1.
- Códigos de erro estáveis: `rate_limited`, `invalid_schema`, `upstream_unavailable`, `unauthorized`, `payload_too_large`, `internal_error`. Corpo de erro HTTP: `{ "error": { "code", "message", "retryAfterMs"? } }`.
- Sessão: JWT HS256 curto em cookie `sid` `HttpOnly`; token inválido ou expirado → 401 e a web inicia nova sessão. CORS restrito a `ALLOWED_ORIGIN`; `POST` exige `content-type: application/json` e, se houver `Origin`, ele deve ser `ALLOWED_ORIGIN`.
- SSE: `id: <seq>`, heartbeat (comentário `: hb`), `retry:` definido pelo servidor, retomada por `Last-Event-ID` a partir do buffer (janela de 200 eventos por sessão).
- Limites: `bodyLimit` = `LIMITS.maxEventBytes` (65536); rate limit por sessão e por IP; capacidade máxima de sessões.
- Logs estruturados (pino) com `sessionId`/`correlationId`, sem dados pessoais; cookies redigidos.
- Commits convencionais; atualizar `CHECKLIST.md` no mesmo commit que conclui o item; reivindicar a frente no `WORKBOARD.md` antes de codar (skill `workboard-protocol`).
- Identificadores e comentários de código em inglês; documentação em português.

## Review Focus

Entradas que o spec não detalha e que mais provavelmente quebram:

1. **Reenvio com o mesmo `id` depois de uma falha do upstream** deve ser reprocessado, não engolido como duplicado (o `error` leva o `messageId`; a fila de reenvio da web reusa o `id`). Testes nas Tarefas 4 e 9.
2. **Cliente que desconecta o SSE** não pode vazar listeners nem timers de heartbeat; os eventos seguintes continuam indo ao buffer. Teste na Tarefa 8.
3. **Corpos fora do esperado** (acima de 64 KB, `content-type` errado, JSON inválido, `sessionId` de outra sessão) devem virar códigos de erro estáveis (413/415/400/403), nunca 500. Teste na Tarefa 7.
4. **Cookie válido, mas sessão perdida** (instância reciclada) deve dar 401 `unauthorized`, para a web abrir sessão nova; nunca um stream vazio nem 500. Testes nas Tarefas 7 e 8.
5. **Chatbot que trava ou envia linhas gigantes** é limitado pelo timeout do turno e por um teto de tamanho de linha; uma linha inválida vira `internal_error`, não derruba o processo. Testes na Tarefa 6.

```ts
import { z } from 'zod';
import { ClientEventSchema, ServerEventSchema } from './events';
import { err, ok, type Result } from './result';

/** Gateway → chatbot: body of `POST /v1/chat/events`. */
export const ChatbotRequestSchema = z.object({
  v: z.literal(1),
  sessionId: z.string().min(1).max(128),
  correlationId: z.string().min(1).max(128),
  event: ClientEventSchema,
});
export type ChatbotRequest = z.infer<typeof ChatbotRequestSchema>;

const [
  text,
  voice,
  code,
  location,
  template,
  carousel,
  quickReplies,
  flow,
  typing,
  delivered,
  read,
  error,
] = ServerEventSchema.options;

/** A server event as the chatbot emits it: the gateway assigns `seq`. */
export const UnsequencedServerEventSchema = z.discriminatedUnion('type', [
  text.omit({ seq: true }),
  voice.omit({ seq: true }),
  code.omit({ seq: true }),
  location.omit({ seq: true }),
  template.omit({ seq: true }),
  carousel.omit({ seq: true }),
  quickReplies.omit({ seq: true }),
  flow.omit({ seq: true }),
  typing.omit({ seq: true }),
  delivered.omit({ seq: true }),
  read.omit({ seq: true }),
  error.omit({ seq: true }),
]);
export type UnsequencedServerEvent = z.infer<typeof UnsequencedServerEventSchema>;

/** Parses one NDJSON line of the chatbot response. */
export function parseChatbotLine(line: string): Result<UnsequencedServerEvent, Error> {
  let json: unknown;
  try {
    json = JSON.parse(line);
  } catch {
    return err(new Error('chatbot line is not valid JSON'));
  }
  const r = UnsequencedServerEventSchema.safeParse(json);
  return r.success ? ok(r.data) : err(r.error);
}

export function serializeChatbotLine(event: UnsequencedServerEvent): string {
  return `${JSON.stringify(event)}\n`;
}
```

```ts
import { err, ok, type Result } from '@seguradora/protocol';
import { z } from 'zod';

const flag = (fallback: 'true' | 'false') =>
  z
    .enum(['true', 'false'])
    .default(fallback)
    .transform((v) => v === 'true');

const int = (fallback: number, min = 0) => z.coerce.number().int().min(min).default(fallback);

export const ConfigSchema = z
  .object({
    PORT: z.coerce.number().int().min(1).max(65535).default(8080),
    HOST: z.string().min(1).default('0.0.0.0'),
    LOG_LEVEL: z
      .enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent'])
      .default('info'),
    CHATBOT_URL: z.string().url(),
    SESSION_SECRET: z.string().min(32),
    ALLOWED_ORIGIN: z.string().url(),
    COOKIE_SECURE: flag('true'),
    COOKIE_SAME_SITE: z.enum(['none', 'lax', 'strict']).default('none'),
    TRUST_PROXY: flag('true'),
    SESSION_TTL_SECONDS: int(43200, 60),
    MAX_SESSIONS: int(1000, 1),
    BUFFER_CAPACITY: int(200, 1),
    SEEN_CAPACITY: int(500, 1),
    HEARTBEAT_MS: int(15000, 10),
    SSE_RETRY_MS: int(3000, 0),
    CHATBOT_CONNECT_TIMEOUT_MS: int(5000, 1),
    CHATBOT_TURN_TIMEOUT_MS: int(60000, 1),
    CHATBOT_RETRIES: int(2, 0),
    CHATBOT_RETRY_BASE_MS: int(200, 0),
    CHATBOT_RETRY_MAX_MS: int(2000, 0),
    BREAKER_FAILURE_THRESHOLD: int(5, 1),
    BREAKER_RESET_MS: int(10000, 0),
    BULKHEAD_MAX_CONCURRENT: int(20, 1),
    BULKHEAD_MAX_QUEUE: int(50, 0),
    SESSION_RATE_CAPACITY: int(40, 1),
    SESSION_RATE_PER_SECOND: z.coerce.number().positive().default(10),
    IP_RATE_CAPACITY: int(120, 1),
    IP_RATE_PER_SECOND: z.coerce.number().positive().default(30),
  })
  .superRefine((c, ctx) => {
    if (c.COOKIE_SAME_SITE === 'none' && !c.COOKIE_SECURE) {
      ctx.addIssue({
        code: 'custom',
        path: ['COOKIE_SECURE'],
        message: 'COOKIE_SECURE must be true when COOKIE_SAME_SITE is none',
      });
    }
  });

export type Config = z.infer<typeof ConfigSchema>;

export function loadConfig(env: Record<string, string | undefined>): Result<Config, string[]> {
  const r = ConfigSchema.safeParse(env);
  if (r.success) return ok(r.data);
  return err(r.error.issues.map((i) => `${i.path.join('.') || 'config'}: ${i.message}`));
}
```

```ts
import type { ServerEvent, UnsequencedServerEvent } from '@seguradora/protocol';

export interface Replay {
  events: ServerEvent[];
  /** True when events between the client's last seq and the oldest buffered event are gone. */
  gap: boolean;
}

/** Per-session ring of the most recent server events, with monotonic `seq` starting at 1. */
export class EventBuffer {
  private events: ServerEvent[] = [];
  private nextSeq = 1;

  constructor(private readonly capacity: number) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`EventBuffer: capacity must be an integer >= 1, got ${capacity}`);
    }
  }

  get latestSeq(): number {
    return this.nextSeq - 1;
  }

  append(event: UnsequencedServerEvent): ServerEvent {
    const sequenced = { ...event, seq: this.nextSeq++ } as ServerEvent;
    this.events.push(sequenced);
    if (this.events.length > this.capacity) this.events.shift();
    return sequenced;
  }

  replayAfter(lastSeq: number): Replay {
    const events = this.events.filter((e) => e.seq > lastSeq);
    const firstSeq = this.events[0]?.seq ?? this.nextSeq;
    return { events, gap: firstSeq > lastSeq + 1 };
  }

  /** Drops events the client has acknowledged. */
  trimThrough(lastSeq: number): void {
    this.events = this.events.filter((e) => e.seq > lastSeq);
  }
}
```

```ts
/** Bounded set of recently seen event ids (oldest forgotten first). */
export class IdempotencyCache {
  private readonly ids = new Set<string>();

  constructor(private readonly capacity: number) {
    if (!Number.isInteger(capacity) || capacity < 1) {
      throw new RangeError(`IdempotencyCache: capacity must be an integer >= 1, got ${capacity}`);
    }
  }

  /** Registers the id; returns true when it had already been registered. */
  register(id: string): boolean {
    if (this.ids.has(id)) return true;
    this.ids.add(id);
    if (this.ids.size > this.capacity) {
      const oldest = this.ids.values().next().value;
      if (oldest !== undefined) this.ids.delete(oldest);
    }
    return false;
  }

  forget(id: string): void {
    this.ids.delete(id);
  }
}
```

```ts
export interface TakeResult {
  allowed: boolean;
  retryAfterMs: number;
}

export interface TokenBucketOptions {
  capacity: number;
  refillPerSecond: number;
  maxKeys?: number;
  now?: () => number;
}

/** Token bucket rate limiter keyed by string; the least recently used keys are evicted. */
export class TokenBucket {
  private readonly buckets = new Map<string, { tokens: number; updated: number }>();
  private readonly now: () => number;
  private readonly maxKeys: number;

  constructor(private readonly o: TokenBucketOptions) {
    if (!Number.isInteger(o.capacity) || o.capacity < 1) {
      throw new RangeError(`TokenBucket: capacity must be an integer >= 1, got ${o.capacity}`);
    }
    if (!Number.isFinite(o.refillPerSecond) || o.refillPerSecond <= 0) {
      throw new RangeError(
        `TokenBucket: refillPerSecond must be a finite number > 0, got ${o.refillPerSecond}`,
      );
    }
    this.now = o.now ?? Date.now;
    this.maxKeys = o.maxKeys ?? 10_000;
  }

  take(key: string): TakeResult {
    const t = this.now();
    const bucket = this.buckets.get(key) ?? { tokens: this.o.capacity, updated: t };
    const elapsedSeconds = Math.max(0, t - bucket.updated) / 1000;
    const tokens = Math.min(this.o.capacity, bucket.tokens + elapsedSeconds * this.o.refillPerSecond);
    const allowed = tokens >= 1;

    this.buckets.delete(key);
    this.buckets.set(key, { tokens: allowed ? tokens - 1 : tokens, updated: t });
    if (this.buckets.size > this.maxKeys) {
      const oldest = this.buckets.keys().next().value;
      if (oldest !== undefined) this.buckets.delete(oldest);
    }

    if (allowed) return { allowed: true, retryAfterMs: 0 };
    return {
      allowed: false,
      retryAfterMs: Math.ceil(((1 - tokens) / this.o.refillPerSecond) * 1000),
    };
  }
}
```

```ts
import type { ServerEvent, UnsequencedServerEvent } from '@seguradora/protocol';
import { EventBuffer, type Replay } from './event-buffer';
import { IdempotencyCache } from './idempotency-cache';

export interface SessionStateOptions {
  bufferCapacity: number;
  seenCapacity: number;
}

/** Listeners must not throw: they are called synchronously by `publish`. */
export type Listener = (event: ServerEvent) => void;

/** Everything the gateway remembers about one anonymous session. */
export class SessionState {
  private readonly buffer: EventBuffer;
  private readonly seen: IdempotencyCache;
  private readonly listeners = new Set<Listener>();

  constructor(
    readonly sessionId: string,
    o: SessionStateOptions,
  ) {
    this.buffer = new EventBuffer(o.bufferCapacity);
    this.seen = new IdempotencyCache(o.seenCapacity);
  }

  get listenerCount(): number {
    return this.listeners.size;
  }

  publish(event: UnsequencedServerEvent): ServerEvent {
    const sequenced = this.buffer.append(event);
    for (const listener of this.listeners) listener(sequenced);
    return sequenced;
  }

  subscribe(listener: Listener): () => void {
    this.listeners.add(listener);
    return () => {
      this.listeners.delete(listener);
    };
  }

  replayAfter(lastSeq: number): Replay {
    return this.buffer.replayAfter(lastSeq);
  }

  acknowledge(lastSeq: number): void {
    this.buffer.trimThrough(lastSeq);
  }

  registerEvent(id: string): 'new' | 'duplicate' {
    return this.seen.register(id) ? 'duplicate' : 'new';
  }

  forgetEvent(id: string): void {
    this.seen.forget(id);
  }
}
```

```ts
import type { ServerEvent } from '@seguradora/protocol';
import type { SessionState } from '../domain/session-state';

export interface StreamHandle {
  /** True when some events after `lastSeq` are no longer buffered. */
  gap: boolean;
  unsubscribe: () => void;
}

/**
 * Replays the buffered events after `lastSeq` and then subscribes to live ones. Both
 * happen synchronously, so no event published in between can be missed or duplicated.
 */
export function openStream(
  session: SessionState,
  lastSeq: number,
  sink: (event: ServerEvent) => void,
): StreamHandle {
  const { events, gap } = session.replayAfter(lastSeq);
  for (const event of events) sink(event);
  const unsubscribe = session.subscribe(sink);
  return { gap, unsubscribe };
}
```

```ts
import type {
  ChatbotRequest,
  ClientEvent,
  ErrorCode,
  UnsequencedServerEvent,
} from '@seguradora/protocol';
import type { SessionState } from '../domain/session-state';
import { ChatbotProtocolError } from './errors';
import type { ChatbotPort, Clock, IdGenerator, Logger, RateLimiter } from './ports';

export type HandleResult =
  | { status: 'accepted'; completion: Promise<void> }
  | { status: 'duplicate' }
  | { status: 'rate_limited'; retryAfterMs: number };

export interface HandleClientEventDeps {
  chatbot: ChatbotPort;
  sessionLimiter: RateLimiter;
  ipLimiter: RateLimiter;
  newId: IdGenerator;
  now: Clock;
  logger: Logger;
}

const UNAVAILABLE_MESSAGE = 'O atendimento está indisponível no momento. Tente novamente.';
const INTERNAL_MESSAGE = 'Não foi possível processar a resposta do atendimento.';

const describeError = (error: unknown): { name: string; message: string } =>
  error instanceof Error
    ? { name: error.name, message: error.message }
    : { name: 'UnknownError', message: String(error) };

/** Accepts one client event: limits, idempotency, forwarding to the chatbot, publishing replies. */
export class HandleClientEvent {
  constructor(private readonly d: HandleClientEventDeps) {}

  handle(session: SessionState, event: ClientEvent, clientIp: string): HandleResult {
    const ip = this.d.ipLimiter.take(`ip:${clientIp}`);
    const own = this.d.sessionLimiter.take(`session:${session.sessionId}`);
    if (!ip.allowed || !own.allowed) {
      return {
        status: 'rate_limited',
        retryAfterMs: Math.max(ip.retryAfterMs, own.retryAfterMs),
      };
    }

    if (session.registerEvent(event.id) === 'duplicate') return { status: 'duplicate' };

    switch (event.type) {
      case 'user.ack':
        session.acknowledge(event.payload.lastSeq);
        return { status: 'accepted', completion: Promise.resolve() };
      case 'user.typing':
        return { status: 'accepted', completion: Promise.resolve() };
      default:
        return { status: 'accepted', completion: this.forward(session, event) };
    }
  }

  private async forward(session: SessionState, event: ClientEvent): Promise<void> {
    const log = {
      sessionId: session.sessionId,
      correlationId: event.correlationId,
      messageId: event.id,
    };
    try {
      const request: ChatbotRequest = {
        v: 1,
        sessionId: session.sessionId,
        correlationId: event.correlationId,
        event,
      };

      let replies: AsyncIterable<UnsequencedServerEvent>;
      try {
        replies = await this.d.chatbot.send(request);
      } catch (error) {
        // Nothing reached the chatbot: allow the client to resend the same id.
        session.forgetEvent(event.id);
        this.d.logger.warn({ ...log, err: describeError(error) }, 'chatbot unavailable');
        this.publishError(session, event, 'upstream_unavailable', UNAVAILABLE_MESSAGE);
        return;
      }

      session.publish({
        ...this.base(session, event.correlationId),
        type: 'status.delivered',
        payload: { messageId: event.id },
      });

      try {
        for await (const reply of replies) {
          if (reply.sessionId !== session.sessionId) {
            this.d.logger.warn({ ...log, replySessionId: reply.sessionId }, 'dropped foreign reply');
            continue;
          }
          session.publish(reply);
        }
      } catch (error) {
        this.d.logger.warn({ ...log, err: describeError(error) }, 'chatbot stream failed');
        if (error instanceof ChatbotProtocolError) {
          this.publishError(session, event, 'internal_error', INTERNAL_MESSAGE);
        } else {
          this.publishError(session, event, 'upstream_unavailable', UNAVAILABLE_MESSAGE);
        }
      }
    } catch (error) {
      // Last resort so a completion promise never rejects unobserved.
      this.d.logger.error({ ...log, err: describeError(error) }, 'unexpected failure handling event');
    }
  }

  private base(session: SessionState, correlationId: string) {
    return {
      v: 1 as const,
      id: this.d.newId(),
      sessionId: session.sessionId,
      correlationId,
      ts: new Date(this.d.now()).toISOString(),
    };
  }

  private publishError(
    session: SessionState,
    event: ClientEvent,
    code: ErrorCode,
    message: string,
  ): void {
    session.publish({
      ...this.base(session, event.correlationId),
      type: 'error',
      payload: { code, message, messageId: event.id },
    });
  }
}
```

```ts
import { err, ok, type Result } from '@seguradora/protocol';
import { errors, jwtVerify, SignJWT } from 'jose';
import type { Clock, TokenService } from '../application/ports';

export interface JoseTokenServiceOptions {
  secret: string;
  ttlSeconds: number;
  now?: Clock;
}

/** HS256 JWT whose subject is the session id. */
export class JoseTokenService implements TokenService {
  private readonly key: Uint8Array;
  private readonly now: Clock;

  constructor(private readonly o: JoseTokenServiceOptions) {
    if (o.secret.length < 32) {
      throw new RangeError('JoseTokenService: secret must have at least 32 characters');
    }
    this.key = new TextEncoder().encode(o.secret);
    this.now = o.now ?? Date.now;
  }

  async issue(sessionId: string): Promise<string> {
    const issuedAt = Math.floor(this.now() / 1000);
    return new SignJWT({})
      .setProtectedHeader({ alg: 'HS256' })
      .setSubject(sessionId)
      .setIssuedAt(issuedAt)
      .setExpirationTime(issuedAt + this.o.ttlSeconds)
      .sign(this.key);
  }

  async verify(token: string): Promise<Result<{ sessionId: string }, 'invalid' | 'expired'>> {
    try {
      const { payload } = await jwtVerify(token, this.key, {
        algorithms: ['HS256'],
        currentDate: new Date(this.now()),
      });
      return payload.sub ? ok({ sessionId: payload.sub }) : err('invalid');
    } catch (error) {
      return err(error instanceof errors.JWTExpired ? 'expired' : 'invalid');
    }
  }
}
```

```ts
import type { Clock, IdGenerator, SessionRegistry } from '../application/ports';
import { SessionState } from '../domain/session-state';

export interface RegistryOptions {
  maxSessions: number;
  ttlMs: number;
  bufferCapacity: number;
  seenCapacity: number;
  newId: IdGenerator;
  now: Clock;
}

interface Entry {
  state: SessionState;
  lastSeen: number;
}

export class InMemorySessionRegistry implements SessionRegistry {
  private readonly entries = new Map<string, Entry>();

  constructor(private readonly o: RegistryOptions) {}

  get size(): number {
    return this.entries.size;
  }

  create(): SessionState | undefined {
    if (this.entries.size >= this.o.maxSessions) this.sweep();
    if (this.entries.size >= this.o.maxSessions) return undefined;
    const state = new SessionState(this.o.newId(), {
      bufferCapacity: this.o.bufferCapacity,
      seenCapacity: this.o.seenCapacity,
    });
    this.entries.set(state.sessionId, { state, lastSeen: this.o.now() });
    return state;
  }

  get(sessionId: string): SessionState | undefined {
    const entry = this.entries.get(sessionId);
    if (!entry) return undefined;
    const t = this.o.now();
    if (t - entry.lastSeen > this.o.ttlMs) {
      this.entries.delete(sessionId);
      return undefined;
    }
    entry.lastSeen = t;
    return entry.state;
  }

  touch(sessionId: string): void {
    this.get(sessionId);
  }

  /** Forgets a session immediately; returns whether it existed. */
  remove(sessionId: string): boolean {
    return this.entries.delete(sessionId);
  }

  /** Removes idle sessions; returns how many were removed. */
  sweep(): number {
    const t = this.o.now();
    let removed = 0;
    for (const [id, entry] of this.entries) {
      if (t - entry.lastSeen > this.o.ttlMs) {
        this.entries.delete(id);
        removed++;
      }
    }
    return removed;
  }
}
```

```ts
  /** Every HTTP request that reached the server, including rejected ones. */
  hits: number;
  setBehavior(behavior: Behavior): void;
  close(): Promise<void>;
}

  v: 1,
  id: randomUUID(),
  sessionId: request.sessionId,
  correlationId: request.correlationId,

  payload: { text },

  (text: string): Behavior =>
  (request, res) => {
    res.writeHead(200, { 'content-type': 'application/x-ndjson' });
    res.write(serializeChatbotLine(textEvent(request, text)));
    res.end();
  };

export const failWith =
  (status: number): Behavior =>
  (_request, res) => {
    res.writeHead(status, { 'content-type': 'application/json' });
    res.end('{"error":"fake failure"}');
  };

const readBody = (req: IncomingMessage): Promise<string> =>
  new Promise((resolve, reject) => {
    const chunks: Buffer[] = [];
    req.on('data', (c: Buffer) => chunks.push(c));
    req.on('end', () => resolve(Buffer.concat(chunks).toString('utf8')));
    req.on('error', reject);
  });

export async function startFakeChatbot(initial: Behavior = replyText('ok')): Promise<FakeChatbot> {

    url: '',

    headers: [],

      behavior = b;
    },
    close: () => Promise.resolve(),
  };

    fake.hits++;
    void readBody(req).then(async (raw) => {

      if (!parsed.success) {
        res.writeHead(400);
        res.end();
        return;
      }
      fake.requests.push(parsed.data);
      fake.headers.push(req.headers);
      await behavior(parsed.data, res);
    });
  });

  fake.url = `http://127.0.0.1:${(server.address() as AddressInfo).port}`;
  fake.close = () =>
    new Promise<void>((resolve) => {
      server.closeAllConnections();
      server.close(() => resolve());
    });
  return fake;
}
```

```ts
import { LIMITS, parseChatbotLine, type UnsequencedServerEvent } from '@seguradora/protocol';
import { ChatbotProtocolError } from '../application/errors';

const toEvent = (line: string): UnsequencedServerEvent => {
  const r = parseChatbotLine(line);
  if (!r.ok) throw new ChatbotProtocolError(`invalid chatbot line: ${r.error.message}`);
  return r.value;
};

/** Parses an NDJSON response body into server events, one per line. */
export async function* parseNdjson(
  body: ReadableStream<Uint8Array>,
  maxLineBytes: number = LIMITS.maxEventBytes * 4,
): AsyncGenerator<UnsequencedServerEvent> {
  const decoder = new TextDecoder();
  const reader = body.getReader();
  let buffer = '';
  try {
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      buffer += decoder.decode(value, { stream: true });

      let newline = buffer.indexOf('\n');
      while (newline >= 0) {
        const line = buffer.slice(0, newline).trim();
        buffer = buffer.slice(newline + 1);
        if (line) yield toEvent(line);
        newline = buffer.indexOf('\n');
      }
      if (buffer.length > maxLineBytes) {
        throw new ChatbotProtocolError(`chatbot line exceeds ${maxLineBytes} characters`);
      }
    }
    buffer += decoder.decode();
    const tail = buffer.trim();
    if (tail) yield toEvent(tail);
  } finally {
    // Best effort: release the connection; the original outcome is what matters.
    await reader.cancel().catch(() => undefined);
  }
}
```

```ts
import {
  Bulkhead,
  CircuitBreaker,
  createPolicy,
  TimeoutError,
} from '@seguradora/resilience';
import { ChatbotHttpError } from '../application/errors';

const RETRYABLE_STATUS = new Set([502, 503, 504]);

/** `fetch` rejects with a TypeError on network failures (DNS, refused, reset). */
const isNetworkError = (error: unknown): boolean => error instanceof TypeError;

/** Safe to repeat: the chatbot is idempotent by event id and nothing was delivered. */
export const isSafeToRetry = (error: unknown): boolean =>
  error instanceof TimeoutError ||
  isNetworkError(error) ||
  (error instanceof ChatbotHttpError && RETRYABLE_STATUS.has(error.status));

/** Problems of the upstream itself (not of the request) count towards the circuit breaker. */
export const isUpstreamFailure = (error: unknown): boolean =>
  error instanceof TimeoutError ||
  isNetworkError(error) ||
  (error instanceof ChatbotHttpError && error.status >= 500);

export interface ChatbotPolicyOptions {
  connectTimeoutMs: number;
  retries: number;
  retryBaseDelayMs: number;
  retryMaxDelayMs: number;
  breakerFailureThreshold: number;
  breakerResetMs: number;
  bulkheadMaxConcurrent: number;
  bulkheadMaxQueue: number;
  now?: () => number;
  sleep?: (ms: number) => Promise<void>;
}

/** bulkhead → circuit breaker → retry → timeout, applied to opening the chatbot connection. */
export function createChatbotPolicy(o: ChatbotPolicyOptions) {
  return createPolicy({
    timeoutMs: o.connectTimeoutMs,
    retry: {
      retries: o.retries,
      baseDelayMs: o.retryBaseDelayMs,
      maxDelayMs: o.retryMaxDelayMs,
      shouldRetry: isSafeToRetry,
      ...(o.sleep ? { sleep: o.sleep } : {}),
    },
    breaker: new CircuitBreaker({
      failureThreshold: o.breakerFailureThreshold,
      resetTimeoutMs: o.breakerResetMs,
      isFailure: isUpstreamFailure,
      ...(o.now ? { now: o.now } : {}),
    }),
    bulkhead: new Bulkhead({
      maxConcurrent: o.bulkheadMaxConcurrent,
      maxQueue: o.bulkheadMaxQueue,
    }),
  });
}
```

```ts
import type { ChatbotRequest, UnsequencedServerEvent } from '@seguradora/protocol';
import { ChatbotHttpError, ChatbotProtocolError } from '../application/errors';
import type { ChatbotPort } from '../application/ports';
import { parseNdjson } from './ndjson';

export interface HttpChatbotClientOptions {
  baseUrl: string;
  /** Result of `createChatbotPolicy`: wraps the connection attempt only. */
  policy: <T>(fn: (signal: AbortSignal) => Promise<T>) => Promise<T>;
  /** Upper bound for the whole turn, including reading the reply stream. */
  turnTimeoutMs: number;
  fetchImpl?: typeof fetch;
}

export class HttpChatbotClient implements ChatbotPort {
  private readonly fetchImpl: typeof fetch;
  private readonly url: string;

  constructor(private readonly o: HttpChatbotClientOptions) {
    this.fetchImpl = o.fetchImpl ?? fetch;
    this.url = new URL('/v1/chat/events', o.baseUrl).toString();
  }

  async send(request: ChatbotRequest): Promise<AsyncIterable<UnsequencedServerEvent>> {
    const response = await this.o.policy(async (signal) => {
      const res = await this.fetchImpl(this.url, {
        method: 'POST',
        headers: {
          'content-type': 'application/json',
          accept: 'application/x-ndjson',
          'x-correlation-id': request.correlationId,
        },
        body: JSON.stringify(request),
        signal: AbortSignal.any([signal, AbortSignal.timeout(this.o.turnTimeoutMs)]),
      });
      if (!res.ok) {
        // Best effort: free the connection; the status error is what matters.
        void res.body?.cancel().catch(() => undefined);
        throw new ChatbotHttpError(res.status);
      }
      return res;
    });

    if (!response.body) throw new ChatbotProtocolError('chatbot response has no body');
    return parseNdjson(response.body);
  }
}
```

```ts
import type { ServerEvent } from '@seguradora/protocol';

/** One SSE message: `id` is the event's seq so the browser resumes with `Last-Event-ID`. */
export function formatSseEvent(event: ServerEvent): string {
  // JSON.stringify never emits a raw newline, so `data` is always a single line.
  return `id: ${event.seq}\nevent: ${event.type}\ndata: ${JSON.stringify(event)}\n\n`;
}

/** Parses the `Last-Event-ID` header; anything that is not a safe non-negative integer is 0. */
export function parseLastEventId(header: string | string[] | undefined): number {
  const value = Array.isArray(header) ? header[0] : header;
  if (value === undefined || !/^\d{1,15}$/.test(value)) return 0;
  return Number(value);
}
```

```ts
import cookie from '@fastify/cookie';
import cors from '@fastify/cors';
import {
  err,
  LIMITS,
  ok,
  parseClientEvent,
  type ErrorCode,
  type Result,
} from '@seguradora/protocol';
import Fastify, { type FastifyInstance, type FastifyReply, type FastifyRequest } from 'fastify';
import type { Logger as PinoLogger } from 'pino';
import type { HandleClientEvent } from '../../application/handle-client-event';
import type { RateLimiter, SessionRegistry, TokenService } from '../../application/ports';
import type { Config } from '../../config';
import type { SessionState } from '../../domain/session-state';

export const SESSION_COOKIE = 'sid';

export type AppConfig = Pick<
  Config,
  | 'ALLOWED_ORIGIN'
  | 'COOKIE_SECURE'
  | 'COOKIE_SAME_SITE'
  | 'TRUST_PROXY'
  | 'SESSION_TTL_SECONDS'
  | 'HEARTBEAT_MS'
  | 'SSE_RETRY_MS'

export interface AppDeps {
  config: AppConfig;
  registry: SessionRegistry;
  tokens: TokenService;
  handleClientEvent: HandleClientEvent;
  ipLimiter: RateLimiter;
  logger: PinoLogger;

interface AuthFailure {
  status: 401 | 403;
  code: ErrorCode;
  message: string;
}

function describeStatus(status: number): { code: ErrorCode; message: string } {
  if (status === 413) return { code: 'payload_too_large', message: 'Mensagem grande demais.' };
  if (status === 429) return { code: 'rate_limited', message: 'Muitas requisições.' };
  if (status === 401 || status === 403) return { code: 'unauthorized', message: 'Não autorizado.' };
  if (status >= 400 && status < 500) return { code: 'invalid_schema', message: 'Requisição inválida.' };
  return { code: 'internal_error', message: 'Erro interno.' };
}

const summarizeIssue = (error: { issues: Array<{ path: PropertyKey[]; message: string }> }) => {
  const issue = error.issues[0];
  if (!issue) return 'Evento inválido.';
  const where = issue.path.map(String).join('.') || 'event';
  return `Evento inválido em ${where}: ${issue.message}`.slice(0, 200);
};

export async function buildApp(deps: AppDeps): Promise<FastifyInstance> {
  const { config, registry, tokens, handleClientEvent, ipLimiter, logger } = deps;

  const app = Fastify({
    loggerInstance: logger,
    trustProxy: config.TRUST_PROXY,
    bodyLimit: LIMITS.maxEventBytes,
  });

  await app.register(cors, {
    origin: config.ALLOWED_ORIGIN,
    credentials: true,
    methods: ['GET', 'POST', 'OPTIONS'],
    allowedHeaders: ['content-type', 'last-event-id'],
    maxAge: 600,
  });
  await app.register(cookie);

  app.addHook('onSend', async (_request, reply, payload) => {
    reply.header('x-content-type-options', 'nosniff');
    if (!reply.hasHeader('cache-control')) reply.header('cache-control', 'no-store');
    return payload;
  });

  const deny = (
    reply: FastifyReply,
    status: number,
    code: ErrorCode,
    message: string,
    retryAfterMs?: number,
  ) => {
    if (retryAfterMs !== undefined) {
      reply.header('retry-after', String(Math.max(1, Math.ceil(retryAfterMs / 1000))));
    }
    return reply.status(status).send({
      error: { code, message, ...(retryAfterMs !== undefined ? { retryAfterMs } : {}) },
    });
  };

  app.setErrorHandler((error, request, reply) => {
    const status =
      typeof error.statusCode === 'number' && error.statusCode >= 400 ? error.statusCode : 500;
    if (status >= 500) request.log.error({ err: error }, 'unhandled error');
    const { code, message } = describeStatus(status);
    return deny(reply, status, code, message);
  });

  app.setNotFoundHandler((_request, reply) => deny(reply, 404, 'invalid_schema', 'Rota não encontrada.'));

  /** CSRF guard: browsers always send Origin on cross-site requests. */
  const requireAllowedOrigin = async (request: FastifyRequest, reply: FastifyReply) => {
    const origin = request.headers.origin;
    if (origin !== undefined && origin !== config.ALLOWED_ORIGIN) {
      return deny(reply, 403, 'unauthorized', 'Origem não permitida.');
    }
    return undefined;
  };

  async function authenticate(request: FastifyRequest): Promise<Result<SessionState, AuthFailure>> {
    const token = request.cookies[SESSION_COOKIE];
    if (!token) return err({ status: 401, code: 'unauthorized', message: 'Sessão ausente.' });
    const verified = await tokens.verify(token);
    if (!verified.ok) {
      const message = verified.error === 'expired' ? 'Sessão expirada.' : 'Sessão inválida.';
      return err({ status: 401, code: 'unauthorized', message });
    }
    const session = registry.get(verified.value.sessionId);
    if (!session) return err({ status: 401, code: 'unauthorized', message: 'Sessão expirada.' });
    return ok(session);
  }

  app.get('/health', async () => ({ status: 'ok' }));
  app.get('/ready', async () => ({ status: 'ready' }));

  app.post('/v1/session', { preHandler: requireAllowedOrigin }, async (request, reply) => {
    const limit = ipLimiter.take(`ip:${request.ip}`);
    if (!limit.allowed) {
      return deny(reply, 429, 'rate_limited', 'Muitas requisições. Aguarde um instante.', limit.retryAfterMs);
    }
    const session = registry.create();
    if (!session) {
      return deny(reply, 429, 'rate_limited', 'Capacidade esgotada. Tente novamente em instantes.', 5000);
    }
    const token = await tokens.issue(session.sessionId);
    reply.setCookie(SESSION_COOKIE, token, {
      httpOnly: true,
      secure: config.COOKIE_SECURE,
      sameSite: config.COOKIE_SAME_SITE,
      path: '/',
      maxAge: config.SESSION_TTL_SECONDS,
    });
    return reply.status(201).send({ sessionId: session.sessionId });
  });

  app.post('/v1/events', { preHandler: requireAllowedOrigin }, async (request, reply) => {
    const auth = await authenticate(request);
    if (!auth.ok) return deny(reply, auth.error.status, auth.error.code, auth.error.message);

    const parsed = parseClientEvent(request.body);
    if (!parsed.ok) return deny(reply, 400, 'invalid_schema', summarizeIssue(parsed.error));
    if (parsed.value.sessionId !== auth.value.sessionId) {
      return deny(reply, 403, 'unauthorized', 'Sessão inválida.');
    }

    const result = handleClientEvent.handle(auth.value, parsed.value, request.ip);
    switch (result.status) {
      case 'accepted':
        return reply.status(202).send({ status: 'accepted' });
      case 'duplicate':
        return reply.status(200).send({ status: 'duplicate' });
      case 'rate_limited':
        return deny(reply, 429, 'rate_limited', 'Muitas mensagens. Aguarde um instante.', result.retryAfterMs);
    }
  });

  return app;
}
```

```ts
export interface SseMessage {
  id?: string;
  event?: string;
  data?: string;
}

export interface SseConnection {
  status: number;
  headers: Headers;
  messages: SseMessage[];
  /** Everything received so far, including comments and the retry hint. */
  raw(): string;
  waitFor(count: number, timeoutMs?: number): Promise<SseMessage[]>;
  /** Resolves when the server (or `close`) ended the stream. */
  closed: Promise<void>;
  close(): void;
}

export interface OpenSseOptions {
  cookie?: string;
  lastEventId?: string;
  origin?: string;
}

export async function openSse(url: string, o: OpenSseOptions = {}): Promise<SseConnection> {
  const controller = new AbortController();
  const response = await fetch(url, {
    headers: {
      accept: 'text/event-stream',
      ...(o.cookie ? { cookie: o.cookie } : {}),
      ...(o.lastEventId ? { 'last-event-id': o.lastEventId } : {}),
      ...(o.origin ? { origin: o.origin } : {}),
    },
    signal: controller.signal,
  });

  const messages: SseMessage[] = [];
  let raw = '';
  let notify: () => void = () => {};

  const parseBlock = (block: string) => {
    const message: SseMessage = {};
    for (const line of block.split('\n')) {
      if (line.startsWith('id: ')) message.id = line.slice(4);
      else if (line.startsWith('event: ')) message.event = line.slice(7);
      else if (line.startsWith('data: ')) message.data = line.slice(6);
    }
    if (message.data !== undefined) messages.push(message);
  };

  const closed = (async () => {
    if (!response.body) return;
    const decoder = new TextDecoder();
    const reader = response.body.getReader();
    let buffer = '';
    try {
      for (;;) {
        const { done, value } = await reader.read();
        if (done) break;
        const text = decoder.decode(value, { stream: true });
        raw += text;
        buffer += text;
        let end = buffer.indexOf('\n\n');
        while (end >= 0) {
          parseBlock(buffer.slice(0, end));
          buffer = buffer.slice(end + 2);
          end = buffer.indexOf('\n\n');
        }
        notify();
      }
    } catch {
      // An aborted fetch ends the stream; tests only care that it ended.
    }
    notify();
  })();

  return {
    status: response.status,
    headers: response.headers,
    messages,
    raw: () => raw,
    closed,
    close: () => controller.abort(),
    async waitFor(count, timeoutMs = 2000) {
      const deadline = Date.now() + timeoutMs;
      while (messages.length < count) {
        const remaining = deadline - Date.now();
        if (remaining <= 0) {
          throw new Error(
            `timed out waiting for ${count} SSE messages, got ${messages.length}: ${JSON.stringify(messages)}`,
          );
        }
        await new Promise<void>((resolve) => {
          notify = resolve;
          setTimeout(resolve, Math.min(remaining, 50));
        });
      }
      return messages;
    },
  };
}
```

```ts
  const streams = new Map<string, () => void>();

  app.addHook('onClose', async () => {
    for (const close of [...streams.values()]) close();
  });

  app.get('/v1/stream', { preHandler: requireAllowedOrigin }, async (request, reply) => {
    const auth = await authenticate(request);
    if (!auth.ok) return deny(reply, auth.error.status, auth.error.code, auth.error.message);
    const session = auth.value;
    const lastSeq = parseLastEventId(request.headers['last-event-id']);

    // A reconnect replaces the previous stream of the same session.
    streams.get(session.sessionId)?.();

    reply.hijack();
    const raw = reply.raw;
    raw.writeHead(200, {
      ...reply.getHeaders(),
      'content-type': 'text/event-stream; charset=utf-8',
      'cache-control': 'no-cache, no-transform',
      connection: 'keep-alive',
      'x-accel-buffering': 'no',
    });
    raw.write(`retry: ${config.SSE_RETRY_MS}\n\n`);

    let closed = false;
    let unsubscribe = (): void => undefined;
    let heartbeat: NodeJS.Timeout | undefined;

    const close = (): void => {
      if (closed) return;
      closed = true;
      if (heartbeat) clearInterval(heartbeat);
      unsubscribe();
      if (streams.get(session.sessionId) === close) streams.delete(session.sessionId);
      if (!raw.writableEnded) raw.end();
    };
    const write = (chunk: string): void => {
      try {
        raw.write(chunk);
      } catch (error) {
        request.log.warn({ err: error }, 'sse write failed');
        close();
      }
    };

    streams.set(session.sessionId, close);
    request.raw.on('close', close);

    const handle = openStream(session, lastSeq, (event) => write(formatSseEvent(event)));
    unsubscribe = handle.unsubscribe;
    if (handle.gap) {
      request.log.warn({ sessionId: session.sessionId, lastSeq }, 'sse replay gap');
    }
    if (closed) {
      unsubscribe();
      return;
    }
    heartbeat = setInterval(() => {
      registry.touch(session.sessionId);
      write(': hb\n\n');
```
